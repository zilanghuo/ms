寄样管理技术计算逻辑说明

适用对象：研发、数仓、测试同学。本文基于当前前端、后端和数仓 SQL 反推寄样管理真实查询链路与字段口径。

核心链路： 样品订单来自官方 API 订单状态增强 DWD，人工维护字段来自寄样配置 DIM，视频履约来自寄样订单视频关系 DWS，最终由 ADS 透传给 Java 接口和前端页面。

一、数据链路

dwd.dwd_sales_order_item_market_wide_api_status_realtime -> dws.dws_sales_sample_order_video_relation_realtime -> dws.dws_sales_sample_order_realtime -> ads.ads_sales_sample_order_realtime -> /tk/content/sample/order/* -> sample-ship 页面
序号 层级/模块 表或类 职责 关键逻辑 备注
1 DWD dwd_sales_order_item_market_wide_api_status_realtime 订单明细状态增强灰度表。 承接官方 API 订单和明细，按订单市场业务日期写入；补充 file_buyer_username 作为样品单达人昵称。 寄样链路当前读取灰度表。
2 DIM dim_sales_sample_order_manual_config 人工维护寄样字段。 保存、导入、删除均写入该表；DWS 刷新时按订单 ID、订单明细 ID、SKU ID 关联。 UNIQUE 覆盖写入。
3 DWS 关系 dws_sales_sample_order_video_relation_realtime 样品订单与视频最优履约关系。 订单达人 file_buyer_username 非空后，按 pid + creator_name 匹配全量有效视频，取签收后最早发布的视频。 关系类型为 fulfillment。
4 DWS 列表 dws_sales_sample_order_realtime 寄样管理列表逻辑层。 合并订单、人工维护、账号配置、商品档案、履约关系，计算物流状态、履约状态和逾期天数。 ADS 直接透传。
5 ADS ads_sales_sample_order_realtime 页面查询表。 不重算口径，透传 DWS 全字段，限制 smt >= 202501。 Java 列表、统计、详情、导出均查询该表。
6 Java TkContentSampleOrderController / TkContentSampleOrderServiceImpl 提供页面接口、筛选、导入导出和人工维护写入。 接口根路径为 /tk/content/sample/order；查询读 ADS，写入读写人工配置 DIM。 URL 不使用中划线。

二、接口与底表

序号 接口 方法 读写表 逻辑说明 返回/影响
1/dataLatestTimeGETads.ads_sales_sample_order_realtime查询最大 sdt 和该分区最大 insert_time。返回刷新频率文案。
2/pagePOSTads.ads_sales_sample_order_realtime按筛选条件分页查询列表。返回 SampleOrderPageResponse。
3/summaryPOSTads.ads_sales_sample_order_realtime按相同筛选条件聚合总数、已履约、待跟进、异常和逾期数量。前端当前展示前四项。
4/detailPOSTads.ads_sales_sample_order_realtime按 orderId + orderItemId + skuId 查询单条详情。用于编辑弹窗回填。
5/savePOSTdim.dim_sales_sample_order_manual_config覆盖写入人工维护字段；空值不覆盖已有值。达人佣金默认 10%。
6/import/templateGET无查询表输出导入更新模板表头。模板含订单主键和可编辑字段。
7/import/updatePOSTdim.dim_sales_sample_order_manual_config解析 xls/xlsx，按主键或订单编号 + 寄样 SKU 定位记录后批量写入人工维护字段。支持导出文件回导。
8/deletePOSTdim.dim_sales_sample_order_manual_config按主键写入 is_deleted = 1。软删除人工配置。
9/exportPOSTads.ads_sales_sample_order_realtime按当前筛选和排序导出列表字段。文件名为寄样管理导出.xlsx。

三、字段来源与计算

序号 展示字段 ADS 字段 主要来源 计算规则 空值/默认
1合作站点site_codeDWD 订单取订单站点编码。空值透传。
2合作店铺store_nameDWD 订单取订单市场店铺名称。页面未传店铺时默认四店范围。
3订单编号jijia_order_noDWS当前取 order_id 作为展示订单编号。可用于导出回导匹配。
4PIDpidDWD 订单取订单商品 PID。样品订单和视频关系按 PID 匹配。
5商品名称product_nameDWD + 商品档案优先 DWD 商品名称，其次商品档案中文名称或 SPU 名称。用于业务识别。
6寄样 SKUsample_skuDWD 订单优先 msku，否则取 TikTok SKU ID。导入可用该字段辅助定位。
7寄样主 SKUsample_main_sku商品档案 + DWD优先商品档案 main_sku，其次 DWD spu。不在默认前端列中展示。
8寄样商务sample_owner人工配置 DIM只从人工配置读取。未配置为空。
9合作阶段cooperation_stage_name人工配置 DIM从人工配置读取。空值透传。
10寄样时间sample_time、sample_time_marketDWD 订单北京时间取 order_time_beijing，市场时间取 order_time。页面优先展示市场时间。
11寄样月份sample_month_nameDWS 计算按市场时间拼接年份和月份。格式如 2026年8月。
12寄样渠道sample_channel_name人工配置 DIM人工维护优先。默认线上。
13颜色/尺码sample_color、sample_size商品档案 DIM按店铺 + PID + 订单 MSKU 关联商品档案 SKU，取颜色和尺码。未匹配为空。
14寄样数量sample_qtyDWD 订单取订单明细数量 sale_qty。空值按 0 处理。
15达人 IDcreator_id账号配置 DIM用 DWD file_buyer_username 匹配账号配置 handle_name，取唯一 TikTok UID。未命中为空。
16达人名字creator_nameDWD 订单取 file_buyer_username。关系表要求该字段非空。
17达人等级/性别creator_level_name、creator_gender_name账号配置 + 人工配置账号配置优先，其次人工维护。默认未知。
18是否开单达人is_opened_creator、is_opened_creator_name账号配置 + 人工配置命中账号配置时为 1，否则使用人工配置值。展示为是/否。
19达人佣金creator_commission人工配置 DIM人工维护值。为空时默认 10%。
20物流状态说明logistics_status_desc人工配置 + DWD 订单人工物流说明优先，否则拼接物流商、单号、包裹状态和展示状态。用于详情和导出。
21寄样状态sample_status_nameDWS 计算按人工异常、签收时间、运输状态、物流单号依次判断。只表示物流状态。
22匹配视频matched_video_id、matched_video_publish_time关系 DWS取 fulfillment 最优关系的视频 ID 和发布时间。无关系为空。
23履约字段is_fulfilled、is_fulfillment_overdue、overdue_daysDWS 计算当前是否履约取是否有匹配视频；逾期按签收到视频或当前日期的间隔判断。间隔达到 7 天及以上逾期。

四、视频履约关系算法

序号 步骤 关键字段 来源 逻辑说明 结果
1 筛样品订单 is_sample_order、file_buyer_username DWD 灰度订单表 仅处理样品订单、主键非空、PID 非空、达人昵称非空的数据。 达人信息补齐后才生成关系。
2 确定日调范围 sdt、insert_time DWD 灰度订单表 纳入近 3 天订单，以及近 3 天被 DWD 覆盖写入的历史样品订单。 适配 30 分钟订单刷新和达人晚到。
3 筛视频 pid、creator_account_name、video_id、publish_time 视频配置 DIM 全量有效视频参与匹配，不限制视频日期；要求未删除且关键字段非空。 视频可在寄样很久后发布。
4 匹配关系 pid、creator_name、delivery_time 订单 + 视频 DIM 同 PID、同达人，且视频发布时间晚于签收时间。 关系方向为签收后发布视频。
5 取最优视频 relation_rank DWS 窗口函数 按视频发布时间升序、视频 ID 降序排序，保留第 1 条。 写入 is_best_match = 1。

五、履约和逾期计算

序号 字段 类型 依赖字段 计算逻辑 说明
1 is_fulfilled TINYINT matched_video_id 匹配到 fulfillment 最优视频时为 1，否则为 0。 不限制 7 天。
2 fulfillment_elapsed_days 过程字段 delivery_time、matched_video_publish_time、${currentDate} 已履约时取视频发布时间日期减签收日期；未履约时取当前业务日期减签收日期。 最小为 0。
3 is_fulfillment_overdue TINYINT fulfillment_elapsed_days 有签收时间且履约判断间隔达到 7 天及以上时为 1。 超过 7 天后履约仍记录逾期。
4 overdue_days INT fulfillment_elapsed_days 逾期时为 fulfillment_elapsed_days - 7，否则为 0。 页面仅逾期展示数值。

六、导入更新技术规则

序号 规则 字段 实现位置 说明 异常处理
1表头识别中文或驼峰字段名IMPORT_HEADER_FIELD_MAP扫描前 10 行识别表头。无法识别时报错。
2主键定位orderId、orderItemId、skuId导入 Service模板模式可直接使用三字段主键。缺少主键时走业务键匹配。
3导出回导定位jijiaOrderNo、sampleSku、storeNameADS 查询按订单编号和寄样 SKU 匹配 ADS 记录；店铺存在时一并过滤。匹配多条时要求改用模板主键。
4可编辑字段达人、合作阶段、佣金、寄样商务、渠道、补寄、备注、物流说明、物流异常人工配置 DIM只有存在可编辑值的行才写入。空白行和样例行跳过。
5布尔解析是否开单达人、物流是否异常导入 Service支持 是/否、YES/NO、true/false、1/0。非法值返回行级错误。

七、调度与补数

实时订单增强 灰度 DWD 按 ODS 本次拉取到的订单明细识别变更订单，再写回订单市场业务日期分区。
关系表日调 30 分钟级订单刷新后，关系表按近 3 天订单和近 3 天 DWD 写入历史订单重算，视频 DIM 全量参与。
历史 debug 历史脚本按 smt >= 202501 全量重算，不使用近 3 天窗口。

推荐顺序：灰度 DWD -> 视频 DIM -> 寄样订单视频关系 DWS -> 寄样订单 DWS -> 寄样订单 ADS。
