寄样管理需求文档

本文档对应 bi/tkDashboard/管理模块/寄样管理/寄样管理.html，用于明确寄样记录的列表展示、筛选、编辑保存、数据来源与字段口径。

核心口径：寄样订单信息可通过 TikTok 订单拉取；达人信息通过账号维护数据进行填充；页面编辑保存后，人工维护字段以寄样管理保存结果为准。

一、需求概述

需求名称寄样管理
所属模块tkDashboard / 管理模块
原型页面管理模块/寄样管理/寄样管理.html
优先级高
目标用户商务、运营、寄样跟进人员、管理人员。
核心价值统一管理达人寄样过程，将 TK 样品订单、达人账号档案、寄样商务维护信息合并到一个可查询、可编辑、可导出的寄样台账。

1.1 建设目标

  1. 支持查看寄样列表，按寄样状态、合作阶段、达人等级、寄样商务、达人 / 商品 / 订单关键字筛选。
  2. 支持新增寄样、编辑寄样、删除寄样、导出寄样记录、逾期提醒。
  3. 寄样订单信息从 TikTok 订单中拉取，样品订单可通过订单详情中的 is_sample_order 标识识别。
  4. 达人信息优先从账号维护数据填充，减少人工重复录入达人 ID、达人名称、达人性别、账号归属等信息。
  5. 编辑保存后写入寄样维护数据，后续列表与导出优先展示最新维护值。

二、页面功能

2.1 筛选区

筛选项页面控件取值 / 规则说明
寄样状态下拉已履约、运输中、签收待履约、待发货、已发货、已签收、签收异常。用于识别寄样进度和异常记录。
合作阶段下拉首次合作、二次合作、多次合作。用于区分达人的合作生命周期。
达人等级下拉L3以下、L3、L4、L5、L6、L6+。用于按达人等级筛选寄样记录。
寄样商务下拉Alice Chen、Bob Wang 等人员。来源于寄样维护数据或账号维护归属人员。
达人 / 商品 / 订单组合搜索searchField + 模糊 / 精确 + 关键字。支持达人 ID、达人名字、寄样 SKU、寄样主 SPU、TK 订单号搜索。
逾期提醒按钮筛选默认筛选需跟进的运输中或逾期记录。用于快速定位寄样物流或履约异常。

操作页面操作支持编辑、删除。

2.3 汇总展示

  • 总记录数：展示当前筛选条件下的寄样记录数。
  • 已履约：状态为已履约的记录数。
  • 待跟进：非已履约且非异常状态的记录数。
  • 异常：状态包含异常的记录数，如签收异常。

三、新增 / 编辑寄样

点击“新增寄样”或列表“编辑”进入右侧抽屉。抽屉分为达人信息、商品信息、订单信息、业务信息四部分。

区域字段来源 / 默认值保存规则
达人信息达人ID、达人名字、达人性别、达人等级、是否开单达人账号维护数据优先填充；TK 订单中有达人标识时用于关联。允许编辑保存，达人 ID 为必填。
商品信息定向 Product ID、寄样主SPU、寄样SKU、商品名称、寄样颜色、尺码、寄样数量TK 样品订单与商品档案。寄样主SPU、寄样SKU、寄样数量为必填；保存后覆盖寄样台账展示值。
订单信息TK订单编号、合作店铺、合作站点、寄样渠道、物流状态、补寄情况TK 订单、物流状态、人工维护。TK订单编号用于回查订单；物流状态和补寄情况可人工维护。
业务信息寄样商务、寄样时间、寄样状态、合作阶段、达人佣金、备注账号维护归属人员、TK 订单时间、人工维护。寄样商务、寄样时间、寄样状态、达人佣金为必填；保存后刷新列表和更新时间。

3.1 保存规则

  1. 点击保存时校验必填项：达人ID、寄样主SPU、寄样SKU、寄样数量、寄样商务、寄样时间、寄样状态、达人佣金。
  2. 来自 TK 订单的字段可作为默认值；业务人员在页面编辑后，寄样维护表中的值作为最终展示值。
  3. 来自账号维护的达人字段可自动填充；若页面编辑保存了不同值，应记录为寄样记录的人工维护值，不直接反写账号维护。
  4. 保存后关闭抽屉，刷新列表、汇总数据和数据更新时间。
  5. 删除操作为逻辑删除，记录进入回收站或删除状态，不直接物理删除原始订单数据。

四、数据来源与处理流程

4.1 数据来源

来源用途关键字段说明
TikTok 订单拉取寄样订单基础信息。TK订单编号、下单 / 寄样时间、店铺、站点、商品 ID、SKU、数量、物流状态、is_sample_order。通过订单详情中的样品订单标识识别寄样订单。
账号维护填充达人信息和归属信息。TikTok UID、Handle Name、账号定位性别、运营人员、内容挂车店铺、账号状态。达人 ID 或账号 Handle 与订单达人信息匹配后带出。
商品档案补充寄样主SPU、商品名称、商品品类等。PID、SPU、SKU、产品主 SKU、商品中文名、主图、品牌、品类。用于将订单 SKU 与业务商品主数据打通。
寄样维护数据保存页面编辑字段。达人等级、合作阶段、寄样商务、达人佣金、补寄情况、备注、人工修正字段。人工维护字段优先展示。

4.2 处理流程

  1. 同步 TikTok 订单数据，筛选 is_sample_order = true 的样品订单。
  2. 按订单中的达人标识、账号 Handle 或 TikTok UID 关联账号维护数据，补充达人名字、达人性别、归属人员等信息。
  3. 按订单商品 ID / SKU 关联商品档案，补充寄样主SPU、商品名称、商品主数据。
  4. 合并寄样维护数据，覆盖或补齐人工编辑字段。
  5. 生成寄样管理列表，并按状态、阶段、等级、商务、关键字等条件查询。
  6. 点击编辑保存后，更新寄样维护数据；下次查询时以维护数据和最新订单状态合并展示。

4.3 数据覆盖优先级

  1. 原始订单标识、TK订单编号等追溯字段以 TikTok 订单为准。
  2. 达人名称、性别、账号归属默认以账号维护为准。
  3. 商品 SPU、商品名称默认以商品档案为准。
  4. 寄样状态、商务、佣金、补寄情况、备注等业务维护字段以寄样管理编辑保存结果为准。

五、导出与异常提醒

  • 导出：默认导出当前筛选条件下的寄样记录；字段应包含列表字段和编辑抽屉中的完整维护字段。
  • 逾期提醒：用于快速筛选运输中、签收待履约或超过配置时限仍未履约的记录。
  • 异常标记：签收异常、物流超时、补寄记录等需要在列表中高亮，并进入异常统计。
  • 数据更新时间：正式页面需要展示订单同步时间或寄样台账更新时间。

六、验收标准

  1. 页面可从首页「管理模块 / 寄样管理」进入。
  2. 列表字段覆盖寄样时间、寄样月份、达人、商务、SKU、主SPU、TK订单编号、寄样状态、合作阶段、达人等级、达人性别、是否开单达人。
  3. 筛选区支持状态、阶段、等级、商务和达人 / 商品 / 订单组合搜索。
  4. TK 样品订单可通过 is_sample_order 标识拉取并进入寄样列表。
  5. 达人信息可通过账号维护数据填充，并支持在寄样记录中编辑保存。
  6. 点击编辑可维护达人信息、商品信息、订单信息、业务信息，保存后刷新列表。
  7. 逾期提醒、异常记录和导出功能符合页面展示口径。
