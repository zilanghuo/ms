通用约定

项说明
Base URL建议商品档案使用 /tk/content/product/archive；账号维护使用 /tk/content/account
请求格式GET 使用 query string；POST 使用 application/json；导入使用 multipart/form-data
响应格式application/json；导出、模板下载接口返回文件流
字段命名接口请求参数、返回参数统一使用 camelCase；底层 Doris 字段仅在“对应底表字段”中使用小写下划线
分页page 从 1 开始，pageSize 默认 20；响应返回 total、list
时间格式日期 YYYY-MM-DD；日期时间 YYYY-MM-DD HH:mm:ss
搜索规则手填搜索统一使用 searchField、searchKeyword、exactSearchKeyword。模糊搜索按 LIKE，精确搜索按 IN；两者同时传入时叠加生效
用户视图自定义列、视图保存等偏通用能力可走统一用户配置接口，本接口文档只说明页面调用点，不单独展开公共接口

统一响应结构

{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}

一、商品模块：商品档案

页面结构包含 SPU 看板 / PID 看板 / SKU 看板 三个栏目，筛选区、操作区、列表区、展开 SKU 明细、编辑抽屉与导出动作。基础数据来源于 TK API 与积加商品主数据，人工维护字段沉淀到商品档案配置。

通用能力说明：平台、店铺可复用公共配置接口或前端固定选项；状态、品类、品牌、负责人按本章节下拉选项接口提供；产品说明、自定义列配置可使用通用用户配置能力。

1.1 共用请求参数

参数类型必填说明
viewTypestring是看板类型：spu、pid、sku
platformCodestring否平台：tiktok、site；空表示全部平台
storeNamesarray<string>否所属店铺列表；空表示全部店铺
productStatusstring否商品状态，如在售、停售
productCategorystring否产品品类
productBrandstring否产品品牌
operatorOwnerstring否负责运营 / 负责人
searchFieldstring否搜索字段：spu、pid、sku；SPU 看板默认 spu
searchKeywordstring否模糊搜索关键词
exactSearchKeywordstring否精确搜索关键词，逗号或换行分隔
sortFieldstring否排序字段，使用接口字段名
sortOrderstring否asc 或 desc
pageinteger否页码，从 1 开始
pageSizeinteger否每页条数

1.2 商品档案下拉选项接口

商品档案筛选区中的状态、品类、品牌、负责人由后端接口返回。四个接口响应结构一致，data 直接返回选项数组，业务字段固定为 label 和 value。

选项接口方法用途
状态/tk/manage/product-archive/options/statusGET返回商品状态筛选项，对应请求参数 productStatus
品类/tk/manage/product-archive/options/categoryGET返回产品品类筛选项，对应请求参数 productCategory
品牌/tk/manage/product-archive/options/brandGET返回产品品牌筛选项，对应请求参数 productBrand
负责人/tk/manage/product-archive/options/operator-ownerGET返回负责运营 / 负责人筛选项，对应请求参数 operatorOwner

请求参数

参数类型必填说明
viewTypestring否看板类型：spu、pid、sku；用于按当前看板粒度裁剪可选项
platformCodestring否平台代码；为空返回全部平台可选项
storeNamesarray<string>否所属店铺列表；为空返回全部店铺可选项

响应 data 字段

字段类型说明
labelstring前端展示文案
valuestring实际提交值，列表查询时传入对应筛选参数

响应示例

{
  "code": 200,
  "msg": "操作成功",
  "data": [
    { "label": "在售", "value": "在售" },
    { "label": "停售", "value": "停售" }
  ]
}

1.9 商品档案导出接口

POST /tk/manage/product-archive/export

按当前筛选条件、当前看板和自定义列配置导出。默认文件名：商品档案_yyyyMMddHHmmss.xlsx。

响应：返回文件流；响应头建议包含 Content-Disposition 文件名。异步导出时可返回 taskId、fileName、downloadUrl。

二、账号模块：账号维护

页面结构包含 全部账号 / 渠道号 / 达人号 / TAP 机构号 四个 Tab，筛选区、统计栏、列表区、新增/编辑抽屉、导入导出、自定义列、删除/回收站、操作日志等能力。账号维护为手动维护数据源，不依赖第三方 API。

安全约定：邮箱密码、TK 密码等敏感字段必须加密或脱敏存储；列表和导出默认不返回明文。若后续需要查看明文，应增加二次确认与权限校验接口。

2.1 共用请求参数

参数类型必填说明
accountTypestring否账号类型：渠道号、达人号、TAP 机构号；空表示全部账号
siteCodestring否国家 / 站点，如 US、UK、AU、CA、DE、FR
accountStatusstring否账号状态：活跃、暂停、停用
operatorOwnerstring否运营人员 / 最新商务归属
creatorSourcestring否达人来源；达人号、TAP 机构号栏目使用
creatorLevelstring否达人等级；达人号、TAP 机构号栏目使用
searchFieldstring否搜索字段：all、handle、uid、nickname、email
searchKeywordstring否模糊搜索关键词
exactSearchKeywordstring否精确搜索关键词，逗号或换行分隔
sortFieldstring否排序字段：handleName、tiktokUid、accountStatus、siteCode 等
sortOrderstring否asc 或 desc
pageinteger否页码，从 1 开始
pageSizeinteger否每页条数，支持 20/50/100

2.2 Tab 计数与统计栏接口

POST /tk/content/account/summary

按当前筛选条件返回四个 Tab 计数和账号状态统计。Tab 计数忽略当前 Tab 类型过滤，但保留其他筛选条件。

{
  "siteCode": "US",
  "accountStatus": "",
  "operatorOwner": "",
  "searchField": "all",
  "searchKeyword": "",
  "exactSearchKeyword": ""
}
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "tabCounts": {
      "all": 10,
      "channel": 3,
      "creator": 5,
      "tapAgency": 2
    },
    "statusCounts": {
      "total": 10,
      "active": 8,
      "paused": 1,
      "disabled": 1
    }
  }
}

响应 data 字段

字段类型说明
tabCounts.allinteger全部账号数量
tabCounts.channelinteger渠道号数量
tabCounts.creatorinteger达人号数量
tabCounts.tapAgencyintegerTAP 机构号数量
statusCounts.totalinteger当前 Tab + 筛选条件下账号总数
statusCounts.activeinteger活跃账号数
statusCounts.pausedinteger暂停账号数
statusCounts.disabledinteger停用账号数

校验规则：handleName 必填；tiktokUid 必填且为 18~19 位数字；accountType、accountStatus、accountGender 必须符合枚举；handleName 变更时可自动生成 tiktokHomeUrl。

2.6 导入导出接口

POST /tk/content/account/export

导出按当前筛选结果生成 Excel，不包含邮箱密码、TK 密码等敏感凭证明文。导入模板与导入接口不在本期实现范围。

导出响应：返回文件流；响应头建议包含 Content-Disposition 文件名。异步导出时可返回 taskId、fileName、downloadUrl。
