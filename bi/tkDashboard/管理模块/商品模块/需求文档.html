商品档案 — 需求文档

以商品主数据管理为目标，建设「商品档案」列表与编辑能力。原型页面：商品档案.html；数据来源：TikTok 商品 API、积加 SPU 接口，最终沉淀为可导出的商品档案 Excel。

一、需求一：商品档案列表

优先级高
影响面运营、商品、商务、直播、投放等围绕商品进行协同的角色。
价值统一 SKU / SPU / PID 商品档案视图，减少跨平台、跨系统人工查询和 Excel 合并成本，为后续销售、库存、投放分析提供稳定商品维度。

1.1 需求描述

  • 目标：在管理模块中新增「商品档案」页面，支持 SKU 看板与 SPU 看板切换。
  • 范围：优先覆盖 TikTok 商品；同时预留独立站平台筛选口径，满足后续多平台商品档案统一管理。
  • 入口：bi/tkDashboard/index.html 管理模块下进入「商品档案」。
  • 原型：bi/tkDashboard/管理模块/商品模块/商品档案.html。

1.2 页面能力

  1. 支持 SKU 看板 / SPU 看板 两个视角切换。
  2. 支持按 平台 筛选：全部平台、TikTok、独立站。
  3. 支持按状态、品类、品牌、负责人进行组合筛选。
  4. 支持按 SPU 或 PID 进行模糊搜索、精确搜索。
  5. 列表展示商品基础信息、商品状态、TK 审核状态、SPU、PID、价格、负责人等字段。
  6. 支持导出列表，导出结果作为最终商品档案 Excel。

1.3 商品档案行数据字段

商品档案的「编辑字段」也是列表行数据的一部分，只是部分字段默认不在列表主表格中展示。最终 Excel 需包含完整行数据字段，并通过字段说明标识是否在列表展示、是否在编辑抽屉展示。

二、需求二：商品档案编辑

优先级高
影响面运营维护商品名称、品类、价格、人员归属等字段。
价值将平台同步字段与业务维护字段统一在商品档案中管理，避免运营多处维护不一致。

2.1 编辑范围

  • 基础信息：商品中文名、销售状态、PID 作用、产品品类、季节。
  • 价格信息：日常折线价、吊牌价、直播间秒杀价、活动报名价、亚马逊定价、独立站价格、公开佣金、定向佣金、广告佣金。
  • 归属人员：负责运营、负责商务、负责指导、负责剪辑、直播运营、投放负责人。
  • 保存方式：点击编辑进入侧边抽屉，保存后更新商品档案维护字段，并刷新列表更新时间。

2.2 编辑规则

  1. 平台同步字段默认只读，不允许覆盖 TikTok API 原始状态、审核状态等字段。
  2. 业务维护字段允许编辑，保存后作为商品档案最终输出值。
  3. 当 TikTok API 与积加 SPU 接口均有同名字段时，优先展示业务侧 SPU 口径；平台字段保留用于追溯。
  4. 编辑保存需记录更新人、更新时间；原型阶段先展示更新时间，后续接口设计中补充审计字段。

三、数据来源与处理流程

3.1 数据来源

来源用途关键字段说明
TikTok 商品 API获取平台商品基础信息、店铺、站点、主图、商品状态、审核状态、价格等。PID、店铺、站点、商品名称、商品状态、审核状态、主图、价格。作为 TikTok 商品档案主来源。
积加 SPU 接口补充业务侧 SPU、中文名、品牌、品类等商品主数据。SPU、商品中文名、品牌、品类、SKU / 商品编码。用于将平台 PID 与业务 SPU 体系打通。
商品档案维护数据保存页面编辑字段。PID、SPU、价格、人员归属、PID 作用、季节、更新时间。人工维护字段优先从本表读取。
独立站数据预留独立站商品和价格口径。平台、SPU、商品编码、独立站价格。当前页面已预留平台筛选。

3.2 处理流程

  1. 定时或手动同步 TikTok 商品 API，得到 PID 维度平台商品基础数据。
  2. 调用积加 SPU 接口，根据 SKU、商品编码、PID 映射关系补充业务 SPU 信息。
  3. 合并商品档案维护数据，覆盖或补齐人工维护字段。
  4. 生成 SKU 看板明细；按 SPU 聚合或去重后生成 SPU 看板视图。
  5. 页面列表查询时按平台、状态、品类、品牌、负责人、SPU / PID 搜索条件返回结果。
  6. 点击导出时，将当前筛选结果导出为最终商品档案 Excel。

3.3 最终 Excel

  • 文件名：商品档案_yyyyMMddHHmmss.xlsx。
  • Sheet1：商品档案完整行数据，包含列表已展示字段和编辑抽屉中维护但列表未展示的字段。
  • Sheet2：字段说明，说明每个字段来源、列表是否展示、编辑是否展示、是否可编辑、口径备注。
  • 导出范围：默认导出当前筛选条件下的数据；后续可扩展为导出全部。

四、验收标准

  1. 页面可从首页「管理模块 / 商品档案」进入。
  2. 页面提供 SKU 看板、SPU 看板切换入口。
  3. 页面提供全部平台、TikTok、独立站筛选条件。
  4. 商品档案字段覆盖列表已展示字段，以及编辑抽屉中维护但列表未展示的价格、人员、知识产权、内容运营字段。
  5. 点击编辑可维护商品基础信息、价格信息、人员归属信息。
  6. 导出结果可作为最终商品档案 Excel 使用，并能追溯字段来源。
