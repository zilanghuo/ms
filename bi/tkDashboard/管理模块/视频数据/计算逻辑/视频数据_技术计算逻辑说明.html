视频数据技术计算逻辑说明

适用对象：研发、数仓、测试同学。本文基于当前前端、后端和数仓 SQL 反推视频数据查询链路、字段来源和计算口径。

核心链路： ODS 视频表现数据先沉淀 DWD 日快照明细，再由视频 DIM 取最新全量快照做基础信息，并结合 DWD 累计指标、寄样订单视频关系、PID 广告消耗和人工维护字段，形成页面当前生效视频配置。

一、数据链路

ods.ods_traffic_file_tiktok_video_performance_di -> dwd.dwd_sales_tiktok_video_performance_detail_di -> dim.dim_sales_tiktok_video_config -> /tk/content/video/* -> video-data 页面
序号 层级/模块 表或类 职责 关键逻辑 备注
1ODSods_traffic_file_tiktok_video_performance_di视频表现原始导入表。业务上按全量快照使用，DIM 取最大 sdt 作为基础信息来源。命名为 di，但按 df 理解。
2DWD 明细dwd_sales_tiktok_video_performance_detail_di保留每日源分区视频表现快照。smt/sdt 保持 ODS 源分区，publish_smt/publish_sdt 按发布时间派生；仅写入 20260601 之后源分区。表现明细弹窗直接查询。
3DWS 关系dws_sales_sample_order_video_relation_realtime提供视频关联样品订单、款号、颜色和首次订单日期。按视频粒度聚合订单号、寄样 SKU、寄样颜色，并影响开单状态和开单日期。依赖寄样链路。
4DIM 主表dim_sales_tiktok_video_config视频管理当前生效配置表。合并最新 ODS 基础信息、DWD 累计指标、人工维护、寄样关系和广告投放标记。主列表查询表。
5JavaTkContentVideoController / TkContentVideoServiceImpl提供视频列表、详情、维护、导入导出、表现明细接口。主列表读 DIM，表现明细读 DWD，保存和导入更新写 DIM。接口根路径 /tk/content/video。

三、DIM 字段计算

序号 字段 字段名 主要来源 计算逻辑 默认/保护
1分区与主键smt/sdt/store_name/video_id/account_typeODS 最新快照smt/sdt 由 publish_time 派生。不是源 ODS 分区。
2PIDpid人工维护 + ODS人工 PID 优先；其次从人工商品名末尾括号数字解析；最后从源商品名末尾括号数字解析。特殊手动商品会置空。
3达人 IDcreator_id人工维护 + ODS人工维护优先，否则取源达人 ID；data_source_name 为 shoudong 时输出空。保留 source_creator_id 追溯。
4商品名称product_name人工维护 + ODS人工维护优先，否则取源商品名称。特殊手动商品会置空。
5视频链接video_url已有值 + ODS已有值非空保留；为空时按 https://www.tiktok.com/@达人昵称/video/视频ID 拼接。达人名前自动补 @。
6累计指标播放、互动、订单、GMV 等DWD 视频表现明细按视频粒度汇总 20260601 之后 DWD 明细。空值按 0。
7累计比率GPM、点击率、引流率、完播率、CTORDWD 视频表现明细按累计分子分母重算；完播率按播放量加权平均。分母为 0 时为 0。
8开单状态is_ordered已有值 + 关系表 + DWD 指标已有为 1、已有开单日期、有关联订单或累计 GMV 大于 0 时为 1。只升不降。
9开单日期first_gmv_date已有值 + 关系表 + DWD 指标已有值不覆盖；为空时优先取关联订单最早下单日期，其次取 DWD 明细最早 GMV 日期。DATE 类型。
10是否投放is_ad_videoPID 看板 DWD按店铺 + PID 关联 T-2 dwd_sales_pid_dashboard_wide_di，广告总消耗非 0 为 1。每天更新。
11视频类型data_source_name/video_type_name账号类型account_type=1 为已绑定账号/自制视频；account_type=2 为联盟账号/联盟视频；其他为历史未知。后端也做展示兜底。
12寄样关系字段video_sku/sample_order_ids/video_color_name/display_color寄样订单视频关系 DWS按视频粒度聚合寄样 SKU、订单号和颜色；颜色只在原字段为空时补充。多个值用 / 或逗号拼接。
13内容识别标签is_real_shot_video/is_ai_video/is_ip_video/is_talk_video视频名称FitScene 判 AI/实拍；IP 和口播使用关键词或特殊字符编码识别。可通过接口重算。
14人工维护字段人员、授权码、颜色、脚本、模特、归因标签、备注页面编辑或导入人工维护后置 is_manual_maintained = 1，自动刷新保护主要人工字段。按主键覆盖更新。

四、DWD 明细口径

序号 处理点 关键字段 来源 逻辑说明 影响
1源分区smt/sdtODS保留 ODS 源月和源日，表示导入或快照日期。用于表现明细。
2生效范围sdt >= 20260601DWD 日调仅写入 20260601 及之后源分区。DIM 累计指标同范围。
3发布时间分区publish_smt/publish_sdtODS publish_time由视频发布时间派生，用于视频归属日期。区别于源分区。
4PID 解析pidODS product_name从商品名称末尾数字解析。用于关联主列表和 PID 分析。
5去重源分区 + 店铺 + 视频 + 账号类型 + PIDODS同一源分区内保留源 insert_time 最新记录。避免重复导入放大。
6视频链接video_url达人昵称 + 视频 ID按 TikTok 固定链接规则拼接。供明细导出。

六、调度与补数

DWD 日调 每次删除并重写当前参数覆盖的近两日源分区，仅导入 20260601 之后数据。
DIM 日调 从 ODS 最大 sdt 取最新全量快照做基础信息，指标从 DWD 明细按视频累计。
页面查询 主列表查 DIM 当前生效结果，表现明细查 DWD 源日快照。

推荐调度顺序：ODS 视频表现导入 -> DWD 视频表现明细 -> 寄样订单视频关系 DWS -> DIM 视频配置 -> 页面接口查询。
