视频数据业务计算逻辑说明

适用对象：业务、内容、运营团队。本文按视频数据页面展示内容说明字段含义、筛选项、维护操作和核心业务口径。

一句话理解： 视频数据页面以 TikTok 视频当前生效配置表为主，汇总视频基础信息、商品 PID、达人账号、人工维护标签、寄样订单关系、累计播放和 GMV 指标，用于管理联盟视频、自制视频和全部视频。

一、页面数据范围

主列表底表 dim.dim_sales_tiktok_video_config
表现明细底表 dwd.dwd_sales_tiktok_video_performance_detail_di
数据粒度 发布时间所属月、发布时间所属日、店铺、视频 ID、账号类型。
刷新频率 页面文案为一天 2 次，8:50 与 16:50，数量范围为 20260601 后。

页面主列表直接查询视频 DIM 当前生效数据；视频表现明细弹窗查询 DWD 日快照明细，用于查看同一视频在不同源日期下的表现指标。

二、页面栏目与筛选

序号 筛选项 接口字段 底表字段 筛选逻辑 说明
1视频栏目videoTabaccount_type全部视频查全部；联盟视频固定 account_type = 2；自制视频取非联盟账号类型。页签会分别查询数量。
2站点/店铺siteCode、storeNamestore_name站点用于联动店铺下拉；店铺传入后精确过滤。店铺选项来自公共接口。
3发布时间startDate、endDatepublish_time按发布时间区间过滤，开始日补 00:00:00，结束日补 23:59:59。前端默认最近 14 天。
4是否开单orderedStatusis_ordered是/否转为 1/0 精确匹配。开单状态只升不降。
5是否投放adStatusis_ad_video是/否转为 1/0 精确匹配。来自 PID 看板 T-2 广告消耗判断。
6内容标签realShotStatus、aiStatus、ipStatus、talkStatusis_real_shot_video 等按是否实拍、AI、IP、口播分别过滤。标签可自动识别，也可重算。
7归因标签sampleShopAttribution、sampleAttributionTag、relationAttributionTag对应归因字段精确匹配店铺归属、寄样归因标签、关系归属标签。主要来自人工维护或导入。
8人员ownerNameowner_business、sample_business、editor_name、director_name任一人员字段等于筛选值即命中。人员下拉汇总多个字段。
9关键词searchField、searchMode、keyword视频、达人、商品、PID、款号等字段模糊搜索使用 LIKE；精准搜索支持多值 IN。默认字段兜底为视频 ID。

10商品名称productNameproduct_name人工维护优先，否则取源商品名称；为空时页面显示待补充。维护视频数据入口可补。
11Product IDproductIdpid人工维护优先，其次从商品名称末尾数字解析。也用于 PID 看板和寄样关系。
12样品订单号sampleOrderIdssample_order_ids来源寄样订单视频关系表，多个订单用逗号拼接。说明视频已关联样品订单。
13款号videoSkuvideo_sku来源寄样订单视频关系表中的寄样 SKU，多个款号用斜杠拼接。无关系时为空。
14颜色colorDisplayvideo_color_name、display_color自制视频优先展示展示颜色，否则优先展示视频颜色。可人工维护，空时可由寄样关系颜色补充。
15归属人员多个字段owner_business、sample_business、editor_name、editor_assistant、director_name联盟视频隐藏负责编导；自制视频在店铺归属后展示剪辑专员、剪辑助理、负责编导。人工维护字段。
16归因标签sampleAttributionTag、relationAttributionTag归因标签字段展示寄样归因标签和关系归属标签。人工维护或导入更新。
17内容类型标签realShotVideo、aiVideo、ipVideo、talkVideo对应布尔字段展示是否实拍、AI、IP、口播视频。自动识别，可重算。
18脚本/模特scriptType、modelName、modelGender人工维护字段记录脚本分类、上镜模特和出镜模特性别。编辑或导入维护。
19是否开单/开单日期ordered、firstGmvDateis_ordered、first_gmv_date已有开单、已有开单日期、关联样品订单或累计 GMV 大于 0 时视为开单；开单日期优先保留已有值。开单状态只升不降。
20是否投放adVideois_ad_video按店铺 + PID 关联 T-2 PID 看板 DWD，广告总消耗非 0 为是。每天随 DWD 更新。
21播放量/GMVplayCnt、gmvAmountplay_cnt、gmv_amount来源 DWD 视频表现明细自 20260601 起累计。GMV 以视频归因 GMV 优先，视频 GMV 兜底。
22授权码/备注authCode、remarkauth_code、remark人工维护字段。导出和导入支持更新。

四、视频表现明细

点击列表中的表现明细入口时，页面按视频 ID 和店铺查询 DWD 明细；可选日期范围继续按源分区日期过滤。

序号 指标组 代表字段 来源表 口径说明 展示说明
1基础信息源月份、源日期、店铺、视频 ID、PID、发布时间DWD 视频表现明细保留每日 ODS 源分区快照，并派生发布时间分区。用于追踪每日导入数据。
2互动指标播放量、点赞数、评论数、分享数、新增粉丝数DWD 视频表现明细直接取 ODS 当日快照指标。明细不是累计重算。
3商品行为引流次数、商品曝光、商品点击、去重客户数DWD 视频表现明细直接取 ODS 商品行为指标。用于看挂车转化链路。
4成交指标归因 SKU 订单数、视频 SKU 订单数、成交件数、GMVDWD 视频表现明细区分归因、视频商品、间接成交和 GMV。主列表会对 20260601 后明细累计。
5效率指标GPM、点击率、引流率、完播率、CTORDWD 视频表现明细DWD 保留 ODS 指标；DIM 主列表按累计分子分母重算部分比率。明细弹窗展示源日指标。

五、维护与导入导出

编辑视频记录 / 维护视频数据 / 导入更新 -> 写回 dim.dim_sales_tiktok_video_config -> 页面重新查询 DIM 展示
序号 操作 接口 写入位置 规则 说明
1编辑视频记录/savedim.dim_sales_tiktok_video_config按 smt、sdt、店铺、视频 ID、账号类型定位，更新归属商务、授权码、颜色、人员、脚本、标签、是否投放等维护字段。置 is_manual_maintained = 1。
2维护视频数据/maintain/page、/maintain/savedim.dim_sales_tiktok_video_config面向商品信息缺失记录，主要补商品名称和 Product ID。缺失条件为 PID 空或商品名称为空。
3导入更新/import/updatedim.dim_sales_tiktok_video_config支持模板或导出文件回导，按主键定位视频，更新可维护字段。主键为年月、日期、店铺、视频 ID、账号类型。
4导出视频数据/exportdim.dim_sales_tiktok_video_config按当前筛选和排序导出主列表字段。文件名为视频数据导出。
5导出表现明细/performance/detail/exportdwd.dwd_sales_tiktok_video_performance_detail_di按视频 ID、店铺和可选日期区间导出明细指标。用于排查单视频每日表现。
