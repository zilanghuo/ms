视频数据需求文档

本文档对应 bi/tkDashboard/管理模块/视频数据/视频数据.html，依据最新 TikTok_IT映射表_视频数据.xlsx 的 映射表 sheet 生成，用于明确视频数据页面的列表展示、筛选、编辑维护、导出、数据来源与字段口径。

核心口径：一级模块为「视频数据」；页面同时覆盖「联盟视频」与「自制/图文/AI视频」两套字段体系。列表根据视频类型自动切换展示字段，编辑抽屉展示完整字段分组，导出需覆盖映射表全部 60 个目标字段。

二、页面功能

2.1 筛选区

  1. 视频类型页签：全部视频、联盟视频、自制视频、图文视频、AI视频。
  2. 公共筛选：是否开单、内容类型、年月、日期范围、人员、关键字模糊 / 精确搜索。
  3. 联盟视频筛选：是否投放、挂车店铺、归属商务、视频年月、发布时间范围。
  4. 自制/图文/AI视频筛选：内容类型、剪辑专员、负责编导、内容所属月份、发布日期范围。
  5. 关键字搜索覆盖：视频ID / Post ID、达人账号、达人UID、商品标题、视频款号 / 款号SPU、Product ID、标题文案、SPU名称。

2.2 列表展示

  1. 选择联盟视频时，列表默认展示联盟视频基础信息、商品信息、关键指标和手动维护核心字段。
  2. 选择自制视频、图文视频或 AI 视频时，列表默认展示内容基础信息、商品信息、互动指标、成交指标和手动维护核心字段。
  3. 选择全部视频时，列表使用公共字段合并展示，便于跨类型查询。
  4. 数字字段支持排序，包括播放量、GMV、点赞、评论、收藏、转发、互动数、互动率、自然单量、广告单量、全渠道总单量、自然GMV、广告GMV、全渠道GMV、自然曝光量、自然点击量、CTR、CVR。
  5. 默认隐藏字段不作为列表默认列，但应在编辑抽屉展示并随导出输出。

2.3 编辑维护

自制/图文/AI视频剪辑专员、剪辑助理、负责编导、上镜模特、出镜模特性别、展示颜色、脚本分类、英区是否互通、备注支持在编辑抽屉维护；展示颜色可从寄样管理按达人+SKU匹配带出。

三、计算规则

  • 视频年月：根据联盟视频发布时间自动生成，格式 2025/11。
  • 内容所属月份：根据自制/图文/AI视频发布日期自动生成，格式 2026/03。
  • 所属周：根据发布日期自动计算自然周，周一到周日，格式 2026/03/16-2026/03/22。
  • 联盟视频是否开单：GMV > 0 标记为「是」，否则为「否」。
  • 互动数：点赞 + 评论 + 收藏 + 转发。
  • 互动率：互动数 ÷ 播放量 × 100%。
  • 全渠道总单量：自然单量 + 广告单量。
  • 全渠道GMV($)：自然GMV + 广告GMV。
  • 自然点击率（CTR）：自然点击量 ÷ 自然曝光量 × 100%。
  • 点击转化率（CVR）：全渠道总单量 ÷ 自然点击量 × 100%。
  • 是否开单视频：全渠道总单量 > 0 标记为「是」，否则为「否」。

五、数据来源与处理流程

5.1 数据来源

  • 商务视频回收表 / TikTok API：提供联盟视频基础信息、商品信息和播放成交指标。
  • 剪辑内容信息看板 / TikTok API：提供自制、图文、AI视频基础信息、商品信息、互动指标和成交指标。
  • 手工维护：维护归属商务、授权码、视频颜色、寄样商务、剪辑专员、编导、模特、脚本分类、备注等字段。
  • 寄样管理关联：按达人 + SKU 关联寄样记录，可带出寄样商务、展示颜色等辅助字段。
  • 账号维护 / 商品档案：达人账号可与账号维护联动，Product ID / SPU 可与商品档案联动。

5.2 处理流程

  1. 同步联盟视频、已绑定账号视频、剪辑内容信息看板和 TikTok API 指标数据。
  2. 按视频类型识别联盟视频或自制/图文/AI视频，落入对应字段体系。
  3. 根据发布时间或发布日期生成年月和自然周字段。
  4. 计算开单标记、互动数、互动率、全渠道总单量、全渠道GMV、CTR、CVR等计算字段。
  5. 合并手工维护字段和寄样管理关联字段。
  6. 页面按筛选条件查询，编辑保存后刷新列表；导出时输出完整字段。

六、导出与验收标准

6.1 导出

  • 导出当前筛选条件下的视频记录。
  • 联盟视频导出需覆盖字段 1-20；自制/图文/AI视频导出需覆盖字段 21-60。
  • 默认隐藏字段也必须导出，包括达人UID、所属周、Product ID、产品层级分类、收藏、转发、广告GMV、自然曝光量、自然点击量、CTR、CVR、剪辑助理、上镜模特、出镜模特性别、展示颜色、英区是否互通、备注等。

6.2 验收标准

  1. 页面可从首页「管理模块 / 视频数据」进入，并可跳转到视频数据原型。
  2. 需求文档、原型页面与 TikTok_IT映射表_视频数据.xlsx 字段一致，覆盖 60 个目标字段。
  3. 页签支持全部视频、联盟视频、自制视频、图文视频、AI视频切换。
  4. 筛选区支持是否开单、是否投放、内容类型、年月、店铺、人员、日期范围和关键字搜索。
  5. 列表能根据视频类型切换联盟视频字段或自制/图文/AI视频字段。
  6. 编辑抽屉按二级模块展示字段，并支持维护手动维护字段。
  7. 计算字段口径正确，数字指标支持排序展示。
  8. 导出覆盖完整字段，默认隐藏字段不遗漏。
