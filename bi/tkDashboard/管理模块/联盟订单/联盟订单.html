一、说明

  1. 页面分为达人订单和联盟订单：达人订单按视频展示，联盟订单按订单 + Product ID + SKU ID 展示。
  2. 达人订单的视频链接由系统生成并只读；归属商务、授权码、视频颜色通过现有 POST /tk/content/video/save 保存。
  3. 联盟订单展示联盟团长、商品、金额、佣金和订单状态，不关联视频或达人。
  4. 页面风格、筛选区、表格和按钮体系保持与商品档案页面一致。

二、重新梳理后的准确逻辑

  1. 订单数据来源：统一来源于 ods.ods_sales_file_tiktok_affiliate_order_di，仅使用“达人订单”和“联盟订单”两种订单类型。
  2. 达人订单关联：优先按同店铺内容 ID 直连视频；未命中时按同店铺达人账号 + PID 匹配支付前最近发布的视频，未开单联盟视频也保留。
  3. 联盟订单拆分：按店铺 + 订单 + Product ID + SKU ID 保留明细；订单数按订单 ID 去重，同一订单多 SKU 时 GMV 仅计算一次。
  4. 金额口径：所有订单状态均展示和统计，GMV($) 默认仅累计 USD。

三、数据导入说明

  1. 本期不新增 Excel 导入接口；可继续使用既有订单文件导入能力，完成 DWD → DWS → ADS 加工后供页面查询。
