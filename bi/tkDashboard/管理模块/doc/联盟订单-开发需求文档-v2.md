## 一、功能简介

联盟订单模块用于管理 TikTok 达人通过联盟（Affiliate）计划产生的视频带货数据，核心目标是：

1. **归属管理**：将达人视频的开单记录归属到对应的商务人员（bizOwner）
2. **绩效追踪**：统计各商务人员的订单数、开单率、视频数量等核心指标（GMV 为占位符，后续对齐口径后补充）
3. **寄样联动**：将联盟视频与寄样记录关联，确认「寄样 → 出视频 → 开单」的完整链路
4. **手动维护**：补充 TikTok 后台未提供的字段（授权码、视频颜色、归属商务等）

## 二、数据来源与更新频率

### 2.1 数据源说明

本模块使用**双数据源**导入，两个文件均来自 TikTok 后台手动导出，不依赖实时 API 同步。

| 数据源 | 文件名格式 | 用途 | 关键字段 |
|---|---|---|---|
| **DS2（主数据源）** | `creator_order_all_*.xls` | 联盟交易导出，提供视频ID/达人/内容形式 | 内容ID、达人用户名、商品ID、Seller Sku、内容形式、支付时间 |
| **DS1（金额补充）** | `TK店铺后台-*.xlsx` | 店铺后台订单导出，提供准确买家实付金额 | Order ID、Order Amount |

**导入流程（两步）：**
1. Step A：上传 DS2（creator_order_all），系统按「内容ID（视频ID）」聚合，写入 `affiliate_videos` 表（视频粒度）；同时将所有订单行写入 `affiliate_orders` 表（订单粒度）
2. Step B：上传 DS1（TK店铺后台），系统按 Order ID 关联，补充 `affiliate_orders.order_amount` 字段

**当前阶段 GMV 处理：**
- GMV 字段暂为占位符，显示 `-`
- 待后续确认 GMV 口径后，从 `affiliate_orders.order_amount` 聚合计算

### 2.2 字段来源分类

| 数据类型 | 来源 | 更新方式 |
|---|---|---|
| 视频基础信息（视频ID/达人/发布时间/商品） | 🔵 DS2 导入 | 定期批量导入（建议每周一次） |
| 订单数 / 是否开单 / 开单日期 | 🔵 DS2 导入聚合 | 同上 |
| GMV | 🔵 DS1 导入（占位符，待后续对齐） | 同上 |

### 5.4 表格交互

- **行内编辑：** 归属商务、授权码、视频颜色、视频链接、挂车店铺、备注 支持点击直接编辑
- **批量操作：** 勾选多行后，顶部出现批量操作栏（批量分配归属商务）
- **视频链接：** 视频链接列显示「查看」按钮，点击在新标签页打开 TikTok 视频
- **寄样联动：** 视频颜色列悬停时，若有关联寄样记录（按达人用户名 + SPU 匹配），显示「从寄样带出」提示；若同一达人有多条寄样记录，先按 SPU 配对，匹配不上则提示「请手动维护」
- **分页：** 默认每页 20 条，支持 20/50/100/200/500 条/页

### 5.5 导入功能（3步骤）

**导入类型一：导入联盟交易（DS2，creator_order_all）**

步骤一：下载导入模板（说明 DS2 格式要求）

步骤二：上传 .xls/.xlsx 文件，系统解析并校验：
- 内容ID（视频ID）为空 → 跳过该行
- 内容ID 已存在 → 跳过（不覆盖）
- 内容形式 = 视频 → 写入 affiliate_videos 表（按视频ID聚合）
- 所有行 → 写入 affiliate_orders 表（订单粒度）

步骤三：展示导入结果（新增 N 条视频 / 跳过 N 条 / 新增 N 条订单行 / 失败 N 条）

**导入类型二：导入订单金额（DS1，TK店铺后台）**

步骤一：下载导入模板（说明 DS1 格式要求）

步骤二：上传 .xlsx 文件，系统按 Order ID 关联，补充 order_amount 字段

步骤三：展示导入结果（匹配 N 条 / 未匹配 N 条）

### 5.6 寄样联动逻辑

当联盟视频记录中的「达人用户名」和「视频款号（SPU部分）」能在寄样管理中找到对应记录时：
- 「寄样商务」字段自动填入对应寄样记录的「寄样商务」
- 「视频颜色」字段可点击「从寄样带出」按钮，自动填入对应寄样记录的「寄样颜色」
- 若同一达人有多条寄样记录，先按 SPU 配对；若匹配不上，弹出提示「请手动维护视频颜色」

## 六、数据库表设计（v2.0，符合阿里规范）

### 6.1 affiliate_videos（视频粒度主表）

```sql
-- 联盟视频主表（视频粒度，以 video_id 为唯一键）
CREATE TABLE affiliate_videos (
  id              VARCHAR(36)    NOT NULL,          -- UUID 主键
  video_id        VARCHAR(50)    NOT NULL,          -- TikTok 视频ID（内容ID），查重主键
  tiktok_id       VARCHAR(100),                     -- 达人账号名（@xxx），来自 DS2.达人用户名
  user_id         VARCHAR(20),                      -- 达人UID，占位符，待账号维护模块关联
  content_type    VARCHAR(50),                      -- 内容形式：视频/橱窗/直播/外部流量计划，来自 DS2.内容形式
  first_order_time BIGINT,                          -- 最早订单支付时间（UTC 毫秒），来自 DS2.支付时间 MIN
  video_year_month VARCHAR(20),                     -- 视频年月（如 2025年8月），系统自动生成
  product_title   TEXT,                             -- 商品标题（多个以逗号拼接），来自 DS2.商品名称
  video_url       VARCHAR(500),                     -- 视频链接，手工维护
  video_sku       TEXT,                             -- 视频款号（Seller SKU，多值逗号拼接），来自 DS2.Seller Sku
  product_id      TEXT,                             -- TikTok Product ID（多值逗号拼接），来自 DS2.商品 ID
  shop_name       VARCHAR(200),                     -- 挂车店铺，手工维护
  order_count     INT            NOT NULL DEFAULT 0, -- 订单总数，来自 DS2 订单行 COUNT
  has_order       TINYINT(1)     NOT NULL DEFAULT 0, -- 是否开单：order_count > 0
  is_running_ad   TINYINT(1)     NOT NULL DEFAULT 0, -- 是否投放：占位符，待广告看板对接
  vv              BIGINT         NOT NULL DEFAULT 0, -- 播放量：占位符
  gmv             DECIMAL(12,2)  NOT NULL DEFAULT 0, -- GMV：占位符，待后续从 DS1 聚合
  -- 手工维护字段
  biz_owner       VARCHAR(50),                      -- 归属商务
  auth_code       VARCHAR(100),                     -- 授权码
  video_color     VARCHAR(50),                      -- 视频颜色
  sample_biz_owner VARCHAR(50),                     -- 寄样商务（从寄样联动）
  remark          TEXT,                             -- 备注
  -- 系统字段
  created_at      BIGINT         NOT NULL,          -- 创建时间（UTC 毫秒）
  updated_at      BIGINT         NOT NULL,          -- 最后更新时间（UTC 毫秒）
  deleted_at      BIGINT,                           -- 软删除时间，NULL 表示未删除
  PRIMARY KEY (id),
  UNIQUE KEY uk_affiliate_videos_video_id (video_id)
);

-- 索引
CREATE INDEX idx_affiliate_videos_content_type  ON affiliate_videos(content_type);
CREATE INDEX idx_affiliate_videos_year_month    ON affiliate_videos(video_year_month);
CREATE INDEX idx_affiliate_videos_biz_owner     ON affiliate_videos(biz_owner);
CREATE INDEX idx_affiliate_videos_has_order     ON affiliate_videos(has_order);
CREATE INDEX idx_affiliate_videos_tiktok_id     ON affiliate_videos(tiktok_id);
CREATE INDEX idx_affiliate_videos_deleted_at    ON affiliate_videos(deleted_at);
```

CREATE INDEX idx_affiliate_orders_video_id   ON affiliate_orders(video_id);

CREATE INDEX idx_affiliate_orders_paid_time  ON affiliate_orders(paid_time);
CREATE INDEX idx_affiliate_orders_deleted_at ON affiliate_orders(deleted_at);

## 八、关于字段显示"-"的说明

字段显示"-"有两种情况：
1. **自动导入字段显示"-"**：TikTok 后台导出数据中该字段为空，属于数据源问题，请检查导出数据是否完整
2. **手工维护字段显示"-"**：该字段尚未填写（归属商务/授权码/视频颜色等），请进入行内编辑或编辑抽屉补充

可通过筛选栏筛选「归属商务为空」等条件，批量找出待维护的记录。
