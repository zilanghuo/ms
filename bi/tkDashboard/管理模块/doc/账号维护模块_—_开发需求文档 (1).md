**版本：** v1.0 草稿（待 Sweet 确认）
**日期：** 2026-05-25
**状态：** 🟡 前端 UI 骨架已完成（Mock 数据 + localStorage 驱动），待确认后进入数据库接入阶段

## 一、功能简介

账号维护模块用于统一管理公司在 TikTok 平台上运营的所有账号，包含三种账号类型：

| 账号类型 | 说明 | 典型场景 |
|---|---|---|
| **渠道号** | 公司自营的 TikTok 账号 | 品牌官方账号、各区域运营账号 |
| **达人号** | 公司管理的达人/KOL 账号 | 加白合作达人、公司孵化达人 |
| **TAP 机构号** | 以公司名义申请的 TikTok TAP 机构账号 | 用于管理达人合作关系 |

**核心目标：**
1. 统一档案：集中管理所有账号的基础信息、业务归属、后台绑定状态
2. 凭证安全：邮箱密码、TK 密码等敏感字段加密存储，查看时需二次确认
3. 操作审计：记录每次新增/编辑/删除操作，支持变更前后值对比
4. 软删除：删除记录进入回收站，30 天内可恢复

## 二、页面结构

### 2.1 四个 Tab

| Tab | 说明 | 对应筛选条件 |
|---|---|---|
| **全部账号** | 所有类型账号混合展示 | 无类型过滤 |
| **渠道号** | 仅公司自营账号 | `accountType = 渠道号` |
| **达人号** | 仅达人/KOL 账号 | `accountType = 达人号` |
| **TAP 机构号** | 仅 TAP 机构账号 | `accountType = TAP 机构号` |

Tab 计数实时反映当前筛选条件下各类型的账号数量。

### 2.2 顶部统计栏

统计栏实时反映当前 Tab + 筛选条件下的汇总数据：

| 统计项 | 计算方式 |
|---|---|
| 账号总数 | COUNT(*) |
| 活跃账号 | COUNT WHERE accountStatus = 活跃 |
| 暂停账号 | COUNT WHERE accountStatus = 暂停 |
| 停用账号 | COUNT WHERE accountStatus = 停用 |

## 三、字段说明（21 列）

## 五、页面功能规划

### 5.1 顶部操作栏按钮

| 按钮 | 图标 | 功能 |
|---|---|---|
| 新增账号 | Plus | 打开新增抽屉，预填默认值（平台=TikTok，状态=活跃，性别=未知） |
| 导入 ↓ | ArrowDownToLine | 下拉菜单：下载模板 / 上传文件（3步骤导入流程） |
| 导出 ↑ | ArrowUpFromLine | 导出当前筛选结果为 Excel，**不含**邮箱密码/TK密码凭证字段 |
| 自定义列 | SlidersHorizontal | 列显示/隐藏/固定/排序配置 |
| 回收站 | Package | 打开回收站弹窗，查看已删除记录（30天内可恢复） |

### 5.2 筛选栏

| 筛选项 | 类型 | 说明 |
|---|---|---|
| 账号类型 | 单选下拉 | 全部 / 渠道号 / 达人号 / TAP 机构号 |
| 账号状态 | 单选下拉 | 全部 / 活跃 / 暂停 / 停用 |
| 国家/站点 | 单选下拉 | 全部 / US / UK / AU / CA / DE / FR |
| 运营人员 | 单选下拉 | 全部 / 动态读取数据库中已有的运营人员列表 |
| 搜索框 | 文本 | Handle Name / TikTok UID / 邮箱 模糊搜索 |

### 5.3 表格交互

- **行内编辑：** 账号状态、账号类型支持点击直接切换（下拉选择），修改后立即保存并写入操作日志
- **编辑抽屉：** 点击行末「编辑」按钮打开侧边抽屉，展示完整表单（5个分组）
- **多选操作：** 勾选多行后，顶部出现批量操作栏（批量修改状态/类型、批量删除）
- **TikTok 主页：** 显示「主页」按钮，点击在新标签页打开 TikTok 账号主页
- **敏感字段：** 邮箱密码/TK密码在表格中显示 `••••••••••`，点击眼睛图标需二次确认后才显示
- **排序：** 支持点击列头排序（Handle Name / TikTok UID / 账号状态 / 国家/站点）
- **分页：** 默认每页 20 条，支持 20/50/100 条/页

### 5.4 新增/编辑抽屉（5 个分组）

| 分组 | 包含字段 |
|---|---|
| 账号基础信息 | Handle Name（必填）、TikTok UID（必填）、Nickname 昵称、TikTok 主页（自动生成）、平台、国家/站点 |
| 账号分类 | 账号类型（必填）、内容来源（多选）、账号定位性别、自定义标签（预设+自由输入） |
| 业务归属 | 内容挂车店铺、账号归属店铺、运营人员 |
| 后台绑定 | 是否后台绑定店铺（开关）、后台绑定店铺名（条件显示）、Shop Code |
| 登录凭证 | 邮箱、邮箱密码（隐藏）、邮箱登录地址、TK 密码（隐藏）、网络线路、账号状态、备注 |

**表单校验规则：**
- Handle Name：必填，不能为空
- TikTok UID：必填，必须为 18~19 位纯数字，不能与现有记录重复
- 账号类型：必填，必须为枚举值之一
- 账号状态：默认值 `活跃`
- 账号定位性别：默认值 `未知`
- 平台：默认值 `TikTok`
- Handle Name 变化时自动生成 TikTok 主页链接（`https://www.tiktok.com/@{handleName}`）

| 账号类型 | ✅ | 固定选项：渠道号 / 达人号 / TAP 机构号 |

| 内容来源 | ❌ | 多选用英文逗号分隔，固定选项：混剪/实拍/AI/图文 |
| 国家/站点 | ❌ | 固定选项：US / UK / AU / CA / DE / FR |
| 运营人员 | ❌ | 自由文本 |
| 平台 | ❌ | 固定选项：TikTok；空白默认 TikTok |

| Shop Code | ❌ | |
| 账号状态 | ❌ | 固定选项：活跃 / 暂停 / 停用；空白默认「活跃」 |

| 备注 | ❌ | |

**导入流程：**

| 步骤 | 操作 | 说明 |
|---|---|---|
| 步骤一 | 下载模板 | 点击「下载模板」获取标准 Excel 模板（含填写说明 Sheet） |
| 步骤二 | 上传文件 | 拖拽或点击选择 .xlsx 文件，系统解析并校验 |
| 步骤三 | 查看结果 | 显示新增 N 条 / 更新 N 条 / 失败 N 条，失败时可下载错误明细 |

**查重规则：** 以 `tiktok_uid` 为查重主键
- UID 不存在 → 新增记录
- UID 已存在 → **有值字段覆盖更新，空白字段保持原值**（保护手工维护的凭证字段）
- 凭证字段（邮箱密码/TK密码）不在导入模板中，不会被导入覆盖

**导入校验规则：**
- Handle Name 不能为空
- TikTok UID 必须为 18~19 位纯数字
- 账号类型必须为枚举值之一
- 账号定位性别必须为枚举值之一（或空白）

### 5.6 导出功能

- 导出当前筛选结果（所有列，**不含**邮箱密码、TK密码两个敏感字段）
- 格式：Excel（.xlsx）
- 文件名：`账号维护_{日期}.xlsx`
- 数组字段（内容来源、自定义标签）以逗号分隔导出

### 5.7 删除与回收站

- **软删除：** 删除记录不立即从数据库删除，标记 `is_deleted = 1` 并记录删除时间和操作人
- **回收站：** 显示 30 天内已删除的记录，支持恢复（清除 `is_deleted` 标记）
- **彻底删除：** 回收站中可手动彻底删除，或 30 天后自动清理
- **批量删除：** 勾选多行后可批量删除，删除前弹窗确认

### 5.8 操作日志

每次操作（新增/编辑/删除/恢复）自动记录：

| 字段 | 说明 |
|---|---|
| 操作类型 | 新增 / 编辑 / 删除 / 恢复 |
| 操作人 | 当前登录用户 |
| 操作时间 | UTC 毫秒时间戳 |
| 变更字段 | 编辑操作时记录每个字段的变更前/后值 |

操作日志在页面底部折叠面板中展示，支持按记录 ID 过滤。

## 六、数据库表设计（草稿）

### 6.1 账号表 `accounts`

```sql
CREATE TABLE accounts (
  id                  VARCHAR(36)   PRIMARY KEY,
  handle_name         VARCHAR(100)  NOT NULL,
  nickname            VARCHAR(100),
  tiktok_home_url     VARCHAR(500),
  tiktok_uid          VARCHAR(20)   NOT NULL UNIQUE,   -- 查重主键
  platform            VARCHAR(20)   DEFAULT 'TikTok',
  country_region      VARCHAR(10),
  content_shop_name   VARCHAR(200),
  operation_staff     VARCHAR(50),
  account_type        VARCHAR(20)   NOT NULL,           -- 渠道号/达人号/TAP 机构号
  content_sources     VARCHAR(100),                    -- 逗号分隔：混剪,实拍,AI,图文
  custom_tags         TEXT,                            -- 逗号分隔，自由标签
  affiliated_shop_name VARCHAR(200),
  backend_bind_shop   TINYINT(1)    DEFAULT 0,
  backend_shop_name   VARCHAR(200),
  shop_code           VARCHAR(50),
  -- 登录凭证（建议加密存储）
  email               VARCHAR(200),
  email_password      VARCHAR(500),                    -- 建议 AES 加密
  email_login_url     VARCHAR(500),
  tk_password         VARCHAR(500),                    -- 建议 AES 加密
  network_line        VARCHAR(100),
  account_gender      VARCHAR(10)   DEFAULT '未知',
  account_status      VARCHAR(10)   DEFAULT '活跃',
  notes               TEXT,
  -- 系统字段
  is_deleted          TINYINT(1)    NOT NULL DEFAULT 0,
  deleted_at          BIGINT,
  deleted_by          VARCHAR(50),
  created_at          BIGINT        NOT NULL,
  updated_at          BIGINT        NOT NULL,
  created_by          VARCHAR(50),
  updated_by          VARCHAR(50)
);
```

### 6.2 操作日志表 `account_audit_logs`

```sql
CREATE TABLE account_audit_logs (
  id          VARCHAR(36)   PRIMARY KEY,
  account_id  VARCHAR(36)   NOT NULL,
  action      VARCHAR(20)   NOT NULL,    -- 新增/编辑/删除/恢复
  operator    VARCHAR(50),
  changes     TEXT,                      -- JSON：[{field, from, to}]
  created_at  BIGINT        NOT NULL
);
```

> **注意：** 当前前端使用 `localStorage` 存储操作日志，数据库接入后需迁移为服务端持久化。
