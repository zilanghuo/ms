## 一、功能简介

寄样管理模块用于记录和追踪公司向 TikTok 达人寄送样品的全流程，包括：寄样申请录入、物流状态跟踪、履约情况确认、补寄管理，以及与账号维护模块的联动（自动带出达人信息）。

**核心业务场景：**
1. 商务人员在飞书/Excel 维护寄样记录后，批量导入系统
2. 商务人员直接在系统内快速录入单条寄样记录
3. 运营人员追踪物流状态，标记已签收/已履约
4. 发现同一达人同一 SKU 重复寄样时，系统提示并自动标注「补寄」
5. 统计各商务人员的寄样数量、履约率、逾期情况

### 3.3 枚举值说明

**寄样状态（7种）：**

| 状态 | 颜色 | 说明 |
|---|---|---|
| 待发货 | 灰色 | 已录入，尚未发货 |
| 已发货 | 蓝色 | 已从仓库发出，等待签收 |
| 运输中 | 黄色 | 快递在途 |
| 已签收 | 青绿色 | 达人已签收，等待履约 |
| 签收异常 | 红色 | 快递异常（丢件/地址错误等） |
| 签收待履约 | 橙色 | 已签收，但视频/内容尚未发布 |
| 已履约 | 绿色 | 达人已发布内容，合作完成 |

**逾期判断规则：** 状态为「已发货」或「运输中」，且距寄样时间超过 **14 天**，系统自动标记为逾期（橙色警告图标）。

## 四、页面功能规划

### 4.1 顶部统计栏

页面顶部展示 5 个统计卡片（只读，实时统计）：

| 统计项 | 说明 |
|---|---|
| 总寄样数 | 当前筛选条件下的总记录数 |
| 待发货 | 状态为「待发货」的数量 |
| 运输中 | 状态为「已发货」+「运输中」的数量 |
| 逾期未签收 | 超过 14 天未签收的数量（红色警告） |
| 已履约 | 状态为「已履约」的数量 |

### 4.2 筛选栏

| 筛选项 | 类型 | 说明 |
|---|---|---|
| 寄样状态 | 单选下拉 | 全部 / 待发货 / 已发货 / 运输中 / 已签收 / 签收异常 / 签收待履约 / 已履约 |
| 寄样月份 | 月份选择 | 按月筛选，格式：2025年8月 |
| 寄样商务 | 单选下拉 | 按商务人员筛选 |
| 合作阶段 | 单选下拉 | 首次合作 / 二次合作 / 多次合作 |
| 达人等级 | 多选下拉 | L3以下 / L3 / L4 / L5 / L6 / L6+ |
| 搜索框 | 文本搜索 | 支持达人ID / 达人名字 / 寄样SKU / 积加订单编号 模糊搜索 |
| 重置 | 按钮 | 清空所有筛选条件 |

### 4.3 顶部操作栏按钮（从左到右）

| 按钮 | 图标 | 功能 |
|---|---|---|
| 快速录入 | ⚡ | 弹出快速录入弹窗（仅必填字段，6个字段） |
| 导入 ↓ | ArrowDownToLine | 下拉菜单：下载模板 / 上传文件（3步骤导入流程） |
| 导出 ↑ | ArrowUpFromLine | 导出当前筛选结果为 Excel |
| 寄样说明 | FileText | 打开模块说明文档抽屉（静态只读） |
| 回收站 | Trash2 | 查看已删除记录，支持恢复 |
| 操作历史 | Clock | 查看导入/导出/删除操作历史 |
| 自定义列 | Columns | 列显示/隐藏/排序配置 |

### 4.4 表格交互

- **行内编辑：** 寄样状态、物流状态、备注、补寄情况支持点击直接编辑
- **批量操作：** 勾选多行后，顶部出现批量操作栏（批量修改寄样状态、批量分配商务、批量删除）
- **逾期提醒：** 逾期行显示橙色警告图标，悬停显示「已逾期 X 天」
- **补寄标注：** 同一达人ID + 寄样SKU 的第二条记录，「补寄情况」列自动填入「补寄」标注
- **达人信息联动：** 输入达人ID 后，系统自动从账号维护模块查询并填入昵称/性别/等级
- **分页：** 默认每页 20 条，支持 20/50/100/200/500 条/页

### 4.5 快速录入弹窗（6个必填字段）

| 字段 | 说明 |
|---|---|
| 达人ID | 18~19 位纯数字，输入后自动带出昵称 |
| 寄样SKU | 具体寄样 SKU |
| 寄样主SKU | 主 SPU/SKU |
| 寄样数量 | 默认 1 |
| 寄样商务 | 负责人姓名 |
| 达人佣金 | 如「10%」 |

提交后可在完整编辑抽屉中补充其余字段。

### 4.6 完整编辑抽屉（右侧滑出，600px）

分 4 个分组展示所有字段：

| 分组 | 字段 |
|---|---|
| 达人信息 | 达人ID / 达人名字 / 达人性别 / 达人等级 / 是否开单达人 |
| 商品信息 | 寄样SKU / 寄样主SKU / 寄样颜色 / 寄样尺码 / 寄样数量 / 商品名称 / 定向Product ID |
| 订单与物流 | 积加订单编号 / 合作店铺 / 合作站点 / 寄样渠道 / 物流状态 / 补寄情况 |
| 业务信息 | 寄样商务 / 寄样时间 / 寄样状态 / 合作阶段 / 达人佣金 / 备注 |

### 4.7 导入功能（3步骤）

**步骤一：** 下载导入模板（24列，按飞书顺序）

**步骤二：** 上传 .xlsx 文件，系统解析并校验：
- 必填字段为空 → 报错
- 寄样状态枚举值不合法 → 报错
- 达人ID + 寄样SKU 重复 → 弹出查重弹窗，确认是否为补寄

**步骤三：** 展示导入结果（新增 N 条 / 更新 N 条 / 失败 N 条），失败时可下载错误明细 Excel

### 4.8 查重与补寄逻辑

- 查重主键：**达人ID + 寄样SKU**
- 发现重复时：弹出查重弹窗，显示已有记录的寄样时间/状态/积加订单
- 用户确认「补寄」后：新增一条记录，「补寄情况」字段自动填入「补寄」
- 用户取消：不新增记录

## 七、关于字段显示"-"的说明

字段显示"-"有两种情况：
1. **自动带出字段显示"-"**：该达人在账号维护模块中未建档，或商品档案中无对应 SKU 记录，属于数据源问题
2. **手工维护字段显示"-"**：该字段尚未填写，请进入编辑抽屉补充

可通过筛选栏筛选「寄样商务为空」等条件，批量找出待维护的记录。
