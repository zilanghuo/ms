TK 看板 MCP 使用说明

用于让 AI 助手通过标准 MCP 协议查询 TK 看板相关数据。当前仅开放只读查询能力。

安全说明：访问 Token 由技术侧单独发放与维护，本 HTML 文档不重复存放明文 Token。
功能边界 接入地址 可用工具 调用格式 查询示例 参数说明 限流说明 返回说明 启用配置

1. 功能说明

TK 看板 MCP 用于让 AI 助手通过标准 MCP 协议查询 TK 看板相关数据。

当前仅开放只读查询能力，不支持导出、维护更新、企业微信播报、AI SSE 流式分析、补数任务等会产生文件、外部通知或数据变更的操作。

适用场景

  • 查询 PID / SPU 数据看板
  • 查询 PID / SPU 趋势明细
  • 查询 PID 与主推 SPU 维护列表
  • 查询商品统计、SKU 看板、SKU 销量明细、SPU 维度商品统计
  • 查询店铺统计
  • 查询站点、店铺、货币下拉选项
  • 查询各看板最新数据时间

不开放场景

  • Excel 文件导出
  • 企业微信播报
  • AI SSE 流式分析
  • PID 与主推 SPU 更新
  • 补数、同步、维护任务
  • 批量高频导数

2. 接入地址

服务器地址：

http://124.71.39.91:9210

完整请求地址：

POST http://124.71.39.91:9210/mcp/tk

接口路径：

POST /mcp/tk

请求头：

X-MCP-Token: <由技术侧发放的 MCP Token>
Content-Type: application/json
  • MCP 默认关闭，需技术侧配置开启。
  • 未携带 X-MCP-Token 或 Token 错误、禁用、过期时，会拒绝访问。
  • 当前仅支持 JSON-RPC POST 调用，不支持 GET / SSE 流式连接。

4. JSON-RPC 调用格式

查询工具列表：

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/list",
  "params": {}
}

调用工具：

{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "tk_product_stats_query",
    "arguments": {
      "storeName": "xxx店铺",
      "startDate": "2026-07-01",
      "endDate": "2026-07-15",
      "gran": "day",
      "searchField": "spu",
      "exactSearchKeyword": "SPU001,SPU002",
      "page": 1,
      "pageSize": 20
    }
  }
}

6. 参数说明

参数说明
startDate开始日期，格式 YYYY-MM-DD
endDate结束日期，格式 YYYY-MM-DD
storeName店铺名称
storeNames多店铺名称列表，适用于 SPU 维度商品统计
siteName站点名称，可选；用于站点下拉模糊匹配
siteCode站点代码，可选；用于店铺下拉筛选
metric店铺统计指标，qty = 销量，amount = 销售额
displayCurrency销售额展示币种，空或 original 表示原币
minAmount销售额最低额过滤
gran日期粒度，支持 day / week / month / quarter / year
searchField搜索字段，商品统计支持 spu / pid / sku，PID 看板支持 pid / spu
searchKeyword模糊搜索关键词
exactSearchKeyword精确搜索关键词，多个值用英文逗号分隔
pidPID
spuSPU
mainSpu主推 SPU
mainSpuConfigured主推 SPU 是否已配置，空 = 全部，true = 已配置，false = 未配置
page页码，从 1 开始
pageSize每页条数

7. 限流说明

为避免影响 BI 服务和 Doris 查询，MCP 接口启用了单机限流。

限制项默认值
全局 QPS5
单个工具 QPS2
最大并发查询3
单次请求体最大值64KB

如果请求过快，会返回 MCP JSON-RPC 错误：

{
  "error": {
    "code": -32001,
    "message": "Rate limit exceeded"
  }
}

业务侧遇到该错误时，稍后重试即可。

8. 返回说明

MCP 返回内容中会包含原 BI 接口响应 JSON。

正常返回重点字段

字段说明
code原 BI 接口状态码，200 表示成功
msg原 BI 接口提示信息
data实际业务数据

异常返回重点字段

字段说明
error.codeMCP 错误码
error.messageMCP 错误说明
error.data错误补充信息，可能为空

常见错误

错误码含义
-32601MCP 方法不存在
-32602参数错误或工具不存在
-32000工具执行失败
-32001触发限流
-32002请求体过大
-32003Token 缺失、错误、禁用或过期
-32004MCP 未开启

9. 使用边界

这套 MCP 是给 AI 助手代查 TK 看板数据用的，不是替代前端页面，也不是批量导数接口。

  • 只用于查询分析，不用于更新业务数据。
  • 不建议大范围、长周期、高频率拉取数据。
  • 如需正式下载 Excel，请继续使用原系统导出功能。
  • 如需开放更新、导出、播报、AI 分析等能力，需要单独评估权限和风控。

10. 技术侧启用配置

技术侧可按需开启 MCP：

mcp:
  tk:
    enabled: true
    tokens:
      - name: bi-assistant
        token: your-token
        enabled: true
        expire-at: "2026-12-31 23:59:59"
        remark: "BI 助手查询 TK 看板使用"
    max-request-bytes: 65536
    rate-limit:
      enabled: true
      global-qps: 5
      tool-qps: 2
      max-concurrent: 3
      window-seconds: 1
配置说明
mcp.tk.enabled是否开启 TK MCP，默认关闭
mcp.tk.tokens[].nameToken 名称
mcp.tk.tokens[].tokenMCP 访问 Token
mcp.tk.tokens[].enabled当前 Token 是否启用
mcp.tk.tokens[].expire-at当前 Token 过期时间，格式 yyyy-MM-dd HH:mm:ss，为空表示不过期
mcp.tk.tokens[].remarkToken 备注
mcp.tk.max-request-bytes单次请求体大小限制
mcp.tk.rate-limit.enabled是否开启单机限流
mcp.tk.rate-limit.global-qps全局 QPS 限制
mcp.tk.rate-limit.tool-qps单个工具 QPS 限制
mcp.tk.rate-limit.max-concurrent最大并发工具调用数
mcp.tk.rate-limit.window-seconds限流统计窗口，单位秒
