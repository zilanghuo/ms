tkDashboard 销售接口文档

本文档以当前后端 Controller 代码为准，覆盖 TkPidController、TkProductStatsController、TkStoreStatsController、TkOptionsController 已暴露接口。

字段命名：接口请求参数与响应字段使用 Java DTO / VO 驼峰命名；底表字段仍按 Doris 小写下划线命名，如需映射请通过“接口字段 / 对应底表字段”说明。

一、通用约定

请求格式GET 使用 query string；POST 使用 application/json。导出接口通过 TkDashboardHttpUtil.readJsonBodyLoose 兼容 JSON Body 与 Query。
响应格式普通接口返回 BaseResponse<T>；导出接口直接返回文件流。
时间格式请求日期使用 YYYY-MM-DD；分区字段不直接作为接口入参。
搜索规则searchKeyword 为模糊搜索；exactSearchKeyword 为精确搜索，支持逗号分隔。两者同时传入时后端可叠加生效。
{
  "code": 0,
  "message": "",
  "data": { }
}

六、注意事项

  • 当前实际接口路径不再使用旧文档中的 /api/bi/tk/... 前缀，实际 Controller 前缀为 /tk/options、/tk/sales/storeSiteStats、/tk/sales/productStats、/tk/pid。
  • 商品统计 Controller 当前实际路径为 /tk/sales/productStats，不是旧文档中的 product-statistics 或 product-stats 横线命名。
  • PID 与主推 SPU 维护当前仅包含 storeName、pid、mainSpu；如后续增加产品主 SKU，应以新的 DTO 字段为准同步本文档。
  • 导出接口返回文件流，不再包装 BaseResponse。
