发补货 2.0 逻辑 — 需求文档

版本：v2.0｜更新：2026-10-27｜适用范围：TikTok 库存 / 发补货｜统计粒度：站点 × 店铺 × SPU × SKU × 月份

建设目标：以 SPU 为目标管理主体，形成“年度月度目标 → SKU 配比拆分 → 库存与在途覆盖判断 → 发货建议”的闭环。未来销量默认以近 90 天可售日均预测，并保留 SPU 与 SKU 两级人工调整能力；预计入仓时间以积加数据为准，当前头程库存偏低时由直邮优先承接需求。

一、需求范围

模块需求说明输出结果
SPU 目标管理按年度、自然月展示每个 SPU 的日均销量；已发生月份展示实际值，当前及未来月份展示预测值或人工目标。SPU 月度日均销量目标。
SKU 目标拆分SPU 下展开 SKU 目录，按 SKU 在 SPU 内的历史销量占比拆分对应月份目标，并支持逐 SKU 调整。SKU 月度日均销量目标与目标销量。
备货与发货按目标销量、可售库存、在途库存及积加预计入仓时间评估缺口和供给风险。建议备货量、建议发货量、直邮承接提示。

二、目标管理页面

选择年度、站点、店铺 → SPU 月度目标（日均） → 展开 SKU 分配 → 人工调整与留痕 → 计算目标销量与发补货建议
  • 默认按年度展示 1–12 月；每一行是一个 SPU，可展开查看其 SKU 目录。
  • 月度单元格展示 日均销量，统一保留 2 位小数；目标销量按“日均销量 × 当月纳入天数”计算，数量展示保留 2 位小数。
  • 已结束月份展示实际可售日均；当前月展示“已发生实际 + 剩余日期预测”的月度汇总口径；未来月展示预测日均或人工目标日均。
  • 支持站点、店铺、SPU、SKU 查询；SPU/SKU 输入查询同时支持模糊搜索与精确搜索。
  • 提供导出入口，导出当前筛选结果、月度目标、人工调整值、调整人、调整时间及计算来源。

三、日均销量与未来预测口径

3.1 可售日均销量

字段计算口径
可售日该 SKU 在对应业务日存在可售库存，且未标记为库存异常的日期。可售但无成交的日期必须计入分母。
SKU 可售日均观察期内有效订单销量 ÷ 观察期内 SKU 可售天数。
SPU 可售日均SPU 下全部 SKU 有效订单销量之和 ÷ SPU 下全部 SKU 可售天数之和；不得使用各 SKU 日均的简单平均。
有效订单按现有发补货订单口径，排除取消、未支付及金额不大于 0 的记录；订单日期按对应站点时区归属业务日。

3.2 90 天滚动预测

规则明确口径
观察窗口以统计日为截止日，向前连续取 90 个自然日；统计日当天数据未完整时，截止至前一完整业务日。
默认预测值取近 90 天 SPU / SKU 的可售日均销量，作为当前月剩余日期及未来月份的默认预测日均。
月份拆分从统计日开始，将未来连续 90 个自然日按自然月拆分展示。首月或末月不足整月时，仅按该月实际落入窗口的天数展示和计算；例如统计日位于月末，首月可能仅含数天。
年度展示年度视图仍固定展示自然年 1–12 月；超过 90 天窗口的未来月份沿用最近一次有效的 90 天预测值，直到被新的日快照或人工目标覆盖。
无可售历史若近 90 天无可售天数或无有效历史销量，系统不虚构预测值，默认展示 待设置，由运营手动填写 SPU 或 SKU 日均目标。
当前月说明：当前月已发生天数使用实际可售日均，未发生天数使用 90 天预测日均。月度目标销量 = 已发生有效销量 + 预测日均 × 剩余纳入天数；当前月最终月度日均 = 月度目标销量 ÷ 当月纳入天数。

四、人工调整与优先级

调整层级支持内容优先级生效范围
SPU 月度目标可调整某 SPU 指定自然月的日均销量目标。高于系统默认预测。作为该 SPU 当月总目标，并驱动未单独调整 SKU 的分配。
SKU 月度目标可调整某 SKU 指定自然月的日均销量目标或月度目标销量。高于 SPU 月度目标的自动拆分结果。仅影响该 SKU；其余未锁定 SKU 按剩余目标和占比分配。
人工目标留痕保存调整前值、调整后值、调整原因、调整人、调整时间及生效年月。仅由有权限用户修改。后续重算不覆盖人工锁定值，用户取消锁定后恢复系统计算。

优先级：SKU 人工锁定值 ＞ SPU 人工目标拆分值 ＞ 系统 90 天预测值 ＞ 无历史待设置。若 SKU 有历史数据，仍允许人工调整；若无历史数据，也允许直接在 SPU 或 SKU 层级维护。

五、SPU 内 SKU 占比与目标分配

项目计算规则边界处理
SKU 历史销量占比SKU 近90天有效销量 ÷ 同 SPU 全部 SKU 近90天有效销量。按站点、店铺、SPU 分别计算。仅使用同一 SPU 内 SKU；不得跨 SPU 或跨店铺混合。
自动拆分SKU 月度目标销量 = SPU 月度目标销量 × SKU 历史销量占比；SKU 月度日均 = SKU 月度目标销量 ÷ 当月纳入天数。展示值保留 2 位小数；数量分摊产生的尾差归入占比最高、且未锁定的 SKU。
人工锁定 SKU先扣除已锁定 SKU 的月度目标销量，剩余 SPU 目标再按未锁定 SKU 的历史销量占比重新分配。若锁定 SKU 合计已超过 SPU 月度总目标，保留锁定值并提示“SKU 目标超过 SPU 目标”，由运营确认或调整。
无历史 SKU默认占比为 0，不参与自动分摊；可由运营录入 SKU 人工目标。录入后计入 SPU 总目标，且不被日快照自动覆盖。

六、备货与发货联动

SKU 月度目标 → 目标销量 / 日均 → 当前可售库存与在途 → 积加预计入仓时间 → 到仓前需求覆盖 → 发货或直邮承接建议
字段 / 判断计算或取数口径业务结果
积加预计入仓时间从积加头程 / 调拨单据读取每个 SKU 的预计入仓时间；有多个在途批次时按批次保留，并按预计入仓日期顺序累计。作为在途库存可开始覆盖需求的日期，不将未到仓库存当作即时可售库存。
到仓前需求预测日均销量 × max(0, 预计入仓可售日 − 统计日)；跨月时取对应月份的目标日均和实际纳入天数累计。判断当前可售库存能否覆盖下一批货到仓前的销售需求。
预计断货日统计日 + 当前可售库存 ÷ 当前生效日均销量；日均为 0 或待设置时不输出自动断货日。与预计入仓可售日比较，识别供应空窗。
库存空窗期max(0, 预计入仓可售日 − 预计断货日)。空窗期大于 0 时，提示需要直邮承接或调整运输方式。
建议发货量基于目标库存缺口计算；在途库存仅从其预计入仓可售日开始参与覆盖，避免提前冲减缺口。输出待发数量和推荐发货批次。

6.1 当前头程偏低时的直邮规则

  • 当前头程库存偏低、且在途货未能在预计断货日前入仓可售时，系统默认输出 直邮承接，直至最近可用在途批次入仓。
  • 直邮承接数量 = 空窗期内按日均目标计算的需求量；该数量从国内可用库存中预留，不得同时计入可发往海外仓数量。
  • 如国内可用库存不足以覆盖直邮承接量，标记为 直邮库存风险，并按缺口量提示加急采购或调整运输方案。
  • 积加预计入仓时间变更后，系统按最新时间重算空窗期、直邮承接量和建议发货量；人工目标不因重算而被覆盖。

七、材料可生产件数逻辑

目标：将一块（或一批）面料的可用数量，按 SPU × 颜色 归集后换算为可生产件数，判断该同色材料是否能够覆盖该 SPU 下各 SKU 的备货需求。材料只在同一 SPU、同一颜色内参与计算，不跨 SPU 或跨颜色挪用。
面料批次 / 颜色库存 → SPU × 颜色归集 → 扣除不可用与已占用量 → 按 SKU 单件耗料换算 → 可生产件数 → 对比备货缺口与月度目标
字段计算 / 取数口径用途
材料归属每批材料须维护对应 SPU、颜色、材料编码、计量单位及批次；同一 SPU、同一颜色的多批材料可汇总。限定材料可用于哪些 SKU，避免不同款式或不同颜色混用。
材料可用量材料实物库存 − 已锁定用量 − 不可用 / 质检损耗量；统一换算为材料基础单位（如米、千克或码）。作为可生产件数的可支配材料分子。
SKU 单件耗料从 BOM / 工艺资料获取该 SPU × 颜色 × SKU 每生产 1 件所需的材料基础单位；尺码不同可维护不同耗料。确定每个 SKU 的换算系数。
SKU 可生产件数floor(材料可用量 ÷ SKU 单件耗料)。表示现有同色材料若全部用于该 SKU，最多可生产的完整件数。
SPU 同色总可生产件数不直接累加各 SKU 的“可生产件数”（避免重复使用同一块布）；以材料可用量为总约束，在 SKU 分配后计算实际总产出。作为该 SPU 同色材料供给上限。

7.1 同色材料在 SKU 间的分配

步骤规则结果
1. 计算需求取该颜色下各 SKU 的未满足备货缺口；若没有备货缺口，则取对应月份的 SKU 目标销量作为计划需求。同色 SKU 的材料需求件数。
2. 计算优先级默认按 SKU 在该 SPU 内近 90 天历史销量占比由高到低分配；销量占比相同时，按可售天数由低到高分配。人工锁定的 SKU 目标优先满足。确定同一颜色、有限材料下的生产顺序。
3. 换算与扣减每次分配数量不得超过 SKU 需求件数，且消耗材料 = 分配件数 × SKU 单件耗料；剩余材料继续分配给下一 SKU。每个 SKU 的“材料可支持生产数”和材料余额。
4. 余料处理不足 1 件单件耗料的余料保留为材料余额，不计入可生产件数；不同 SKU 的余料不得相互抵扣为成品件。防止材料能力被高估。

7.2 材料风险判断与展示

状态判断条件页面提示
材料充足同色材料可支持生产数 ≥ 同色 SKU 的备货需求件数。展示可生产件数、预计材料余额及可覆盖需求比例。
材料不足同色材料可支持生产数 ＜ 同色 SKU 的备货需求件数。展示材料缺口、受影响 SKU、按优先级未满足的件数，并提示采购 / 追加同色材料。
资料缺失缺少材料归属、材料可用量或 SKU 单件耗料。显示“待维护材料 / BOM”，不输出自动可生产件数，避免以 0 误判为材料不足。

八、展示字段与状态

字段展示要求说明
月度日均销量数字保留 2 位小数。标识实际、系统预测、SPU 人工或 SKU 人工来源。
SKU 销量占比百分比保留 2 位小数并追加 %。展示近 90 天历史销量占比及其计算期间。
月度目标销量 / 建议发货量 / 直邮承接量数字保留 2 位小数。数量同时展示计算来源和更新时间。
预计入仓可售日展示日期、在途批次和积加单据标识。无数据时显示“待积加回传”，不作零库存或已入仓处理。
风险状态正常、需直邮承接、直邮库存风险、SKU 目标超过 SPU 目标、待设置。风险状态支持筛选与导出。

九、待接入与待确认事项

事项当前要求影响
积加预计入仓时间需确认头程 / 调拨单接口可提供 SKU、批次、在途数量、预计入仓时间及状态。决定在途库存何时参与需求覆盖和直邮承接判断。
可售库存日快照需按站点、店铺、SKU 保留每日可售状态与可售库存。决定近 90 天可售日均的分母是否准确。
SKU 与 SPU 映射同一统计日应有唯一有效的店铺、站点、SPU、SKU 映射。保障 SKU 占比和目标拆分不串货。
权限与审计确认 SPU / SKU 月度目标的调整角色、审批需求及调整原因枚举。保障人工目标可追溯、可恢复。
材料与 BOM 数据需提供材料批次库存、材料基础单位、SPU / 颜色归属、已占用量、质检损耗量及 SKU 单件耗料；确认是否存在可跨 SKU 共用的同色材料。决定材料可生产件数和材料不足风险是否能够自动计算。
