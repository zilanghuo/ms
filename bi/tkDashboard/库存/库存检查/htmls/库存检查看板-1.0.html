原型补充说明

  • 不需要需要导出图片
  • 增加数据源：一个是 TK 后台商品管理的库存，另一个是积加后台的库存阀值设置。
  • 需要定时播报：默认为当天的数据情况。
  • 涉及到搜索的，需要调整为多选模式
  • 异常统计卡片：点击阀值同步异常数、少同步异常数、超卖风险异常数等卡片时，可以快速筛选列表数据。
  • SPU 维度明细：SPU 维度下点击某一行数据，可以展开查看该 SPU 下对应的 SKU 数据明细。

产品说明
库存检查看板当前第一个栏目为 SKU 维度库存检查，产品说明参考商品档案的说明展示方式，用于解释商品基础数据与库存检查口径。
  1. 产品基础数据以 TikTok 在线商品为商品范围，按 PID&SKU 维度关联库存数据。
  2. 商品基础信息包含站点、店铺、PID、SKU、SPU、商品名称等，用于和库存数据做统一展示。
  3. 库存检查聚合展示总库存、国内库存、海外在途库存、海外在库库存、店铺应同步库存与实际同步库存。
  4. 库存异常判断以库存差异为核心：差异大于 0 代表少同步，小于 0 代表超卖风险，等于 0 代表同步正确。
  5. SPU 视图基于 PID&SKU 底表按 SPU 聚合生成，库存类数值按 SPU 粒度求和。
