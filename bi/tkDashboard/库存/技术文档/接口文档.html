通用约定

项说明
Base URL当前代码使用 /tk/inventory
请求格式GET 使用 query string；POST 使用 application/json
响应格式application/json；导出接口返回文件流
字段命名接口文档中的请求参数、返回参数统一使用驼峰命名（camelCase）；底层 Doris 表字段命名仅在来源说明中使用下划线命名
分页page（从 1 开始）、pageSize（默认 20）；响应含 total，列表型接口如需表格底部合计行，使用独立字段 totalRow 返回
时间格式日期 YYYY-MM-DD；日期时间 YYYY-MM-DD HH:mm:ss
鉴权待定（Cookie / Token）

统一响应结构

{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}

code !== 200 表示业务错误，msg 为提示信息，data 为接口约定结构。

零、公共说明

当前代码未提供公共筛选接口；站点、店铺、搜索类型等筛选值由前端固定选项或业务侧直接传值。

一、库存检查

对应后端类：TkInventoryCheckController，基础路径：/tk/inventory/check。本章节以代码接口为准，共保留 10 个接口：数据最新时间、PID&SKU 维度汇总/分页/字段说明/导出、SPU 维度汇总/分页/字段说明/展开 SKU 明细/导出。

代码对齐说明：当前代码未提供“异常状态下拉接口”或其他额外库存检查接口；异常状态筛选由前端固定枚举维护。请求和响应字段以 com.ms.bi.api.tkdashboard.request/response 下的 DTO 为准，接口字段使用 camelCase。

以下筛选参数在库存检查汇总、分页、导出接口中复用。历史兼容字段仍按代码保留，但新页面优先使用 siteCodes、storeNames、abnormalType、searchField、searchKeyword、exactSearchKeyword。

参数类型必填适用接口说明

pageinteger否分页页码，从 1 开始；默认 1

viewTypestring否分页/导出历史兼容字段；新接口由 URL 区分 sku / spu 维度
