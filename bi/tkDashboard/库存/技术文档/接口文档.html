通用约定

项说明
Base URL当前代码使用 /tk/inventory
请求格式GET 使用 query string；POST 使用 application/json
响应格式application/json；导出接口返回文件流
字段命名接口文档中的请求参数、返回参数统一使用驼峰命名（camelCase）；底层 Doris 表字段命名仅在来源说明中使用下划线命名
分页page（从 1 开始）、pageSize（默认 20）；响应含 total，列表型接口如需表格底部合计行，使用独立字段 totalRow 返回
时间格式日期 YYYY-MM-DD；日期时间 YYYY-MM-DD HH:mm:ss
鉴权待定（Cookie / Token）

统一响应结构

{
  "code": 0,
  "message": "",
  "data": {}
}

code !== 0 表示业务错误，data 为接口约定结构。

零、公共说明

当前代码未提供公共筛选接口；站点、店铺、搜索类型等筛选值由前端固定选项或业务侧直接传值。

0.1 搜索类型维护方式

原型中库存检查支持 PID / SKU / SPU 搜索，缺补货支持 SPU / SKU 搜索。该接口也可以前端静态写死；若后续需要统一配置，可抽成公共接口。

一、库存检查

对应页面：库存/库存检查/htmls/库存检查看板-1.0.html，需求文档：库存/库存检查/需求文档.html。页面包含两个 Tab：PID&SKU维度、SPU维度。接口按最新原型拆为：每个栏目对应统计接口、列表接口、导出接口三个核心能力；页面数据更新时间随列表或统计接口返回，不单独设计库存检查最新时间接口。

本次调整口径：不再设计“异常状态下拉选项接口”。异常状态筛选项由前端按固定枚举展示；异常卡片点击时通过列表接口的 abnormalType 参数刷新列表，不弹框、不额外请求下拉接口。

1.1 查询条件

  • 视图：sku（PID&SKU维度） / spu（SPU维度）。
  • 站点：按区域级联选择后传 siteCodes；接口只接收站点代码列表。
  • 店铺：传 storeNames 或后续可替换为 storeIds。
  • 异常筛选：固定枚举 all、threshold、lessSync、oversoldRisk；不提供下拉接口。
  • 搜索：使用 searchField + searchKeyword / exactSearchKeyword。SKU 维度支持 pid、sku、spu；SPU 维度固定支持 spu。
  • 日期：最新原型已移除同步日期筛选，接口默认查询最新快照；如后端保留历史能力，可传可选参数 snapshotDate。

1.2 列表接口：库存检查列表

根据当前 Tab 返回对应粒度列表。一个接口通过 viewType 区分 SKU / SPU 两个视图。

POST /tk/inventory/check/page

请求体（JSON）

{
  "viewType": "sku",
  "siteCodes": ["US"],
  "storeNames": ["美国TK-艾斯特尼-美区跨境1店"],
  "abnormalType": "all",
  "searchField": "sku",
  "searchKeyword": "",
  "exactSearchKeyword": "",
  "snapshotDate": "",
  "page": 1,
  "pageSize": 20
}

请求参数说明

参数类型必填说明
viewTypestring是sku / spu
siteCodeslist<string>否站点代码列表；来自前端级联选择结果
storeNameslist<string>否店铺名称列表；后续若接店铺维表，可改为 storeIds
abnormalTypestring否all 全部；threshold 阀值同步异常；lessSync 少同步；oversoldRisk 超卖风险。来自卡片点击或固定筛选项，不需要下拉接口
searchFieldstring否SKU 维度：pid / sku / spu；SPU 维度：spu
searchKeywordstring否模糊搜索关键字
exactSearchKeywordstring否精确搜索关键字，支持逗号或换行分隔，最多 500 项
snapshotDatestring否历史快照日期，格式 YYYY-MM-DD；为空默认最新快照
pagenumber否页码，默认 1
pageSizenumber否每页条数，默认 20
合计行约定：PID&SKU 维度不返回合计行；SPU 维度可返回 totalRow，前端固定展示在列表最后一行，不计入 list 和 total。
