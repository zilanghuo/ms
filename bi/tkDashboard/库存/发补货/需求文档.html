发补货 — 需求文档

本文档已根据 6月4日-TK备货&补货TikTok_IT需求说明_v2.0.docx 与当前原型 htmls/发补货看板-1.0.html 重写；历史 SPU 冗余、发货/补货旧口径内容已移除。

一、需求背景与目标

本文档面向 IT 开发团队，用于落地「TikTok 美国站库存看板 + 备货决策模型」系统。文档包含：

模块一：TK 库存检查看板（PID/SKU 维度）——库存字段定义、数据来源、计算逻辑

模块二：备货决策模型——销售预测、生命周期判断、SKU 分层、目标库存计算、是否备货决策

二、原型入口与页面范围

  • 原型页：发补货看板-1.0.html。
  • 页面仅保留 备货决策模型 一个列表视图；历史 SPU冗余检视、发货、发补货总和 页签已从原型移除。
  • 筛选区保留站点、SKU/SPU 搜索、查询、重置；不再展示数据日期筛选，列表也不展示时间列。
  • 列表基础列为：站点、SPU、SKU、SKU中文名称。
  • 列表业务字段严格按 Word 文档第三模块开始的有序号字段展示，共 48 个。
  • 每个业务字段表头带 ?，鼠标悬停约 0.5 秒后展示该字段的计算/判断逻辑。
  • 每行末尾提供 编辑 功能，允许维护人工判断和建议字段。

五、备货与发货决策字段

以下字段为当前列表展示字段。序号 1–30 来源于备货决策模型，序号 31–48 来源于发货决策模型；字段名和计算逻辑与 Word 文档保持一致。

序号字段名计算 / 判断逻辑说明数据来源备注
1S7（过去7天日均）S7 = 近7天销量 ÷ 7（取前2天起算，避免当日数据不完整）原始7天均值，用于后续比值计算多平台销售表现.销量
2S30（过去30天日均）S30 = 近30天销量 ÷ 30（取前2天起算）原始30天均值，作为波动参考基准多平台销售表现.销量
3S7（过滤后）若某天销量 > S30 × 2，则用S30替换该天数值后重算S7过滤单达人偶发爆发、大促拉动等异常峰值，防止7天数据失真由S7和S30计算得出
4S7/S30 比值S7（过滤后）÷ S30用于判断近期趋势方向计算字段
5动态权重档位S7/S30 ≥ 1.3 → 上涨档（7天权重75%，30天权重25%）
S7/S30 0.8~1.3 → 平稳档（7天权重60%，30天权重40%）
S7/S30 < 0.8 → 下滑档（7天权重40%，30天权重60%）		TikTok内容驱动爆发特性要求权重随趋势动态变化，避免固定权重导致高估或低估计算字段
6加权日均= S7（过滤后）× 对应7天权重 + S30 × 对应30天权重最终用于目标库存计算的预测基准日销量计算字段所有后续计算均基于此值
7生命周期判断需连续 2 个补货观察周期均满足对应条件，才切换生命周期阶段。
上升期：S7/S30 ≥ 1.3，且非内容爆发
平稳期：S7/S30 介于 0.8～1.3
下降期：S7/S30 < 0.8		防止单次短期波动触发错误的生命周期切换（如达人偶发大场后次日即恢复平稳）由S7/S30计算
8是否内容爆发人工标记：若单个达人/单个视频出单占比 > 60%，标记为"内容爆发"内容爆发型上涨不视为真实上升期，不增加安全库存，避免备货过激人工填写（预留字段）未来接入达人出单占比数据后改为自动计算
9商务出单占比该SKU来自商务达人渠道的出单量 ÷ 总出单量辅助判断销量来源是否集中在单一渠道预留字段数据方向可实现，待接入
10剪辑出单占比该SKU来自剪辑视频渠道的出单量 ÷ 总出单量同上预留字段数据方向可实现，待接入
11生命周期阶段系统自动计算输出：上升期 / 平稳期 / 下降期最终使用的生命周期判断结果（含人工override）计算字段支持运营手动修改
12安全库存调整天数（海外仓）上升期：+7天
平稳期：+0天
下降期：-7天		叠加在海外仓基准安全库存天数上由生命周期阶段计算
13安全库存调整天数（直邮仓）上升期：+5天
平稳期：+0天
下降期：-5天		叠加在直邮仓基准安全库存天数上由生命周期阶段计算
14SKU分层（A/B/C/D）A类：该子SKU贡献SPU内前60%销量，且趋势稳定/上升
B类：贡献SPU内60%~90%销量，有稳定销量
C类：贡献SPU内剩余10%销量，动销慢
D类：VOC值 2~3（CCR风险）或 >3（准出联盟风险）		决定备货策略、履约方式、安全库存天数基准由近30天销量占比 + VOC值计算
15是否热卖色码A类 → 是；B/C/D类 → 否标记热卖色码，联动商品统计由SKU分层计算
16VOC值从TikTok店铺后台获取，单位：倍数VOC < 2：安全；VOC 2~3：CCR风险；VOC > 3：准出联盟风险，立即停止海外仓补货TikTok店铺后台（RPA或API接入）
17退货率（近14天）近14天退货量 ÷ 近14天销量超过阈值触发D类降级或停补预留字段（当前手工）后续接入系统自动计算
18建议运输方式A类：海运主力 + 空派救急
B类：海运小批次
C类：直邮优先
D类：停止海外仓补货		由SKU分层自动推荐，运营可override由SKU分层计算
19目标库存（海外仓）= 加权日均 × (补货总天数_海运 + 安全库存天数_海外仓)
示例：A类平稳期 = 加权日均 × (52+30) = 加权日均 × 82天		海外仓目标备货量，用于判断是否需要发货或采购。补货总天数含生产时间计算字段
20目标库存（直邮仓）= 加权日均 × (补货总天数_直邮 + 安全库存天数_直邮仓)
示例：A类平稳期 = 加权日均 × (25+25) = 加权日均 × 50天		直邮仓目标备货量计算字段
21补货总天数（当前）根据当前建议运输方式自动取值：
海运（含采购）：生产20天+海运25天+入仓7天=52天
空派（含采购）：生产20天+排仓4天+空运15天+上架7天=46天
直邮仓补货：生产20天+国内入仓5天=25天		展示当前计算使用的补货链路总天数（补货模型含生产时间）计算字段
22安全库存天数（最终）= 基准安全库存天数 + 生命周期调整天数展示最终使用的安全库存天数，方便运营核查计算字段
23开关1：库存缺口当前总库存 < 目标库存 → 触发备货缺口 = 目标库存 - 总库存，缺口 > 0 才进入后续判断计算字段
24开关2：生命周期下降期 → 不主动补货
D类 → 强制停止补货		即便有缺口，下降期和D类SKU也不触发备货由生命周期阶段和SKU分层判断
25开关3：质量风险VOC 2~3 → 降级处理，转直邮观察，不深备海外仓
VOC > 3 → 立即停止海外仓补货		服装类高退货风险拦截，防止继续补入有品质问题的SKU由VOC值判断
26是否备货三重开关全部通过 → YES，否则 → NO / 观察最终备货决策字段计算字段
27发货缺口= 目标库存（海外仓）- 海外在库总库存
取 MAX(0, 上述结果)		需要从国内仓发往海外仓的数量计算字段
28采购缺口= 目标库存（直邮仓）- 总库存
取 MAX(0, 上述结果)		需要向工厂采购的数量计算字段
29可售天数= 总可用库存 ÷ 加权日均（加权日均为0时显示N/A）当前库存还能支撑多少天销售，越小越紧急计算字段
30备货优先级按可售天数升序排列（可售天数越少，优先级越高）帮助运营判断先补哪个SKU计算字段
31海外有效库存= 海外在库总库存 + 海外在途总量比单纯看在库更准确，避免重复发货计算字段
32海外可售天数= 海外有效库存 ÷ 加权日均还能卖多少天，触发阈值见下计算字段
33发货触发阈值A类：可售天数 < 30天
B类：可售天数 < 20天
C类：可售天数 < 10天		对应各类SKU的安全库存天数基准，低于安全库存即触发由SKU分层和海外可售天数计算
34是否触发发货条件一：海外可售天数 < 发货触发阈值
条件二：海外有效库存 < 目标库存（海外仓）
两条同时满足 → YES		双条件防止在途货已足够时重复触发发货计算字段
35直邮预留量= 直邮加权日均 × 直邮安全库存天数（25天）国内库存同时承担直邮履约，需预留足够库存防止直邮断货计算字段直邮日均销量待确认是否可单独从积加拉取
36国内可发库存= 国内在库库存 - 直邮预留量扣除直邮预留后实际可调拨到海外仓的库存计算字段
37建议发货数量= MIN(国内可发库存, MAX(0, 目标库存（海外仓）- 海外在库 - 海外在途))
即：缺多少补多少，但不超过国内可发上限		核心发货数量公式计算字段
38最小发货批量21KG（卫衣类约25件，T恤类约100件）低于最小批量不触发发货，系统给出提示业务规则
39是否满足最小批量建议发货数量 >= 最小批量对应件数 → 满足
否则 → 提示"数量不足最小批量，建议等待积累后合并发货"		防止频繁小批量发货增加物流成本计算字段
40发货目的仓当前规则：全部发FBT（不考虑三方仓）
FBT目前无库容限制，热卖款优先FBT		未来可扩展：FBT满仓时自动切换三方仓业务规则
41最近截单日下一个周六的日期海派每周截单一次，周六截单，下周三开船系统日期计算
42预计到仓可售日最近截单日 + 32天从截单到FBT上架可售的时间计算字段
43预计断货日今天 + 海外有效库存 ÷ 加权日均按当前销速预计海外库存耗尽日期计算字段
44断货到到仓空窗期= 预计到仓可售日 - 预计断货日（若为负数则无空窗期）空窗期内需直邮衔接。空窗期 > 12天说明直邮撑不住计算字段
45直邮是否可衔接空窗期 <= 12天 → 可衔接（直邮10-12天时效可覆盖）
空窗期 > 12天 → 不可衔接，需提前发货或改空派		12天为直邮时效上限计算字段
46建议运输方式直邮可衔接 → 正常海运，本周六截单

七、页面交互要求

  • 字段说明：业务字段表头统一展示 ?，提示内容取对应字段的计算逻辑、判断逻辑或计算公式。
  • 行编辑：列表末尾提供 编辑 操作，弹窗支持编辑 是否内容爆发、商务出单占比、剪辑出单占比、VOC值、建议运输方式（备货）、建议运输方式（发货）。
  • 搜索：支持 SKU / SPU 的模糊搜索与精确搜索；精确搜索支持一行一项、去重、最多 500 行。
  • 站点：站点筛选沿用 tkDashboard 级联选择组件，支持欧洲、北美洲和 Global。
  • 导出：页面保留导出数据按钮，作为后续导出当前筛选结果的入口。
