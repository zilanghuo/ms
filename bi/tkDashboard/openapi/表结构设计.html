对外提供 API - 表结构设计

本文档沉淀“商品列表查询 / 商品详情查询”当前 tiktok_product* MySQL 表，以及第三个 API“SKU详情关系（积加）”对应的 Doris ODS 层表结构。接口字段使用 camelCase，ODS 底表字段按 Doris 规范统一使用小写下划线。

一、设计说明

1. 表均归属 ods 库，业务域统一为 product；TikTok Shop 官方接口数据按商品域命名为 ods_product_tiktok_*。

2. TikTok 商品接口以接口文档中的 mysql 已有 与 mysql 需新建 的 tiktok_product* 表为准，一张 MySQL 表对应一张 Doris ODS 表。

3. 第三个 API“SKU详情关系（积加）”对应 business_ledger_product，Doris ODS 表继续保留 ods_product_api_jijia_sku_spu_detail_df。

4. 已删除旧版 product_search、product_detail 以及无业务含义的 certification、platform_status、simple_array 等多余设计。

5. DDL 使用 Doris UNIQUE KEY 模型；Key 列前置，字段类型使用 Doris 兼容类型，JSON / 长文本统一使用 STRING。
