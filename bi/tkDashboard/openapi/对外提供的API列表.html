对外提供的 API 列表

版本：v1.0 ｜ 日期：2026-05-15 ｜ 编制：IT 部 ｜ 适用范围：对外服务商 API 接入

参考资料：业务应用API接入规范-TikTok内容中台.pdf（作为接入规范参考之一）

一、文档目的

本文用于沉淀需要提供给外部服务商使用的 API 列表、接入边界、鉴权要求和数据责任口径。当前先形成接口清单 HTML 草稿，后续接口字段、请求示例和错误码可继续在本文件中补齐。

当前约定：外部服务商不直接访问 TikTok Shop API、积加 ERP Open API 或底层 Supabase 数据库，统一通过 IT API 网关访问内容中台开放接口。

二、接入边界

  • 数据来源：内容中台已同步和维护的数据，包括 TikTok Shop API 自动同步数据、积加 ERP API 自动同步数据、运营人工维护数据。
  • 访问方式：外部服务商通过 HTTPS 调用 IT API 网关，由网关完成鉴权、审计、限流和权限控制。
  • 数据范围：默认只开放服务商业务所需的只读查询接口；涉及新增、修改、删除类接口需单独评审。
  • 字段口径：接口入参和出参使用 camelCase，底层表字段或内部字段仍按数仓规范使用小写下划线。

三、API 接口清单

以下为拟开放给外部服务商使用的 API 清单。接口路径、鉴权方式、请求字段和返回字段在服务商范围确认后继续细化。

序号 接口名称 接口路径 方法 接口用途 使用的业务模块 数据来源 备注
1 商品列表查询 /openapi/tiktok-content/products GET 按站点、店铺、商品状态、关键词等条件分页查询内容中台商品基础资料。 tk商品维护 TikTok Shop API 同步商品数据 + 内容中台商品维护数据 用于服务商获取可处理的商品范围；需确认是否返回图片、标题、SPU/SKU、店铺等字段。
2 商品详情查询 /openapi/tiktok-content/product/detail POST 根据商品 ID 查询单个商品详情，包括商品基础信息、站点店铺信息、状态和内容字段。 tk商品维护 TikTok Shop API 同步商品数据 + 内容中台商品维护数据 请求体传入 productId + shopName，避免中文店铺名放在 URL 参数中产生转义问题。
3 商品内容素材查询 /openapi/tiktok-content/products/{productId}/materials GET 查询商品关联的图片、标题、卖点、描述、视频或其他内容素材。 tk商品维护 内容中台人工维护数据 + 商品内容资产 需确认素材 URL 是否需要临时签名、有效期和防盗链策略。
4 任务列表查询 /openapi/tiktok-content/tasks GET 分页查询分配给服务商的内容处理任务。 tk商品维护 内容中台任务数据 如服务商接入场景包含图片处理、标题优化、翻译或内容审核，建议开放该接口。
5 任务结果回传 /openapi/tiktok-content/tasks/{taskId}/result POST 服务商完成内容处理后，回传处理结果、素材地址、状态和异常原因。 tk商品维护 外部服务商回传数据 写入类接口需单独确认幂等键、签名校验、字段校验和回滚策略。
6 枚举字典查询 /openapi/tiktok-content/dictionaries GET 查询站点、店铺、商品状态、任务状态、内容类型等服务商需要使用的枚举字典。 tk商品维护 内容中台配置数据 用于减少接口字段硬编码，建议作为通用基础接口。

3.1 商品列表查询

对外接口说明

该接口面向外部服务商提供商品列表分页查询能力。对外请求参数参考 TikTok Shop Search Products 接口口径，仅保留当前业务可用筛选项，并将字段统一转换为驼峰命名。

参数类型必填示例说明
pageSizenumber是20每页条数，对应 TikTok 原始字段 page_size；建议默认 20，最大值需由网关或服务端限制。
pageNumnumber是1页码，从 1 开始；对外使用页码分页，内部如需对接 TikTok 游标分页，由服务端负责转换。
statusstring否ACTIVATE商品状态，对应 TikTok 原始字段 status；用于筛选在售、下架等状态商品，枚举值以后续实际接入为准。
createTimeGenumber否1714521600创建时间起始值，对应 TikTok 原始字段 create_time_ge；Unix 秒级时间戳，表示查询创建时间大于等于该值的商品。
createTimeLenumber否1717199999创建时间结束值，对应 TikTok 原始字段 create_time_le；Unix 秒级时间戳，表示查询创建时间小于等于该值的商品。
auditStatusstring否AUDITING审核状态，对应 TikTok 原始字段 audit_status；用于筛选审核中、审核通过、审核失败等商品。

对外请求示例

GET /openapi/tiktok-content/products?pageNum=1&pageSize=20&status=ACTIVATE&createTimeGe=1714521600&createTimeLe=1717199999&auditStatus=AUDITING

参数转换说明

  • 对外接口字段统一使用 camelCase，例如 createTimeGe、createTimeLe、auditStatus。
  • 内部对接第三方时再转换为 TikTok 原始下划线字段，例如 create_time_ge、create_time_le、audit_status。
  • 第三方业务参数尽量保留在内部映射层；对外暂只开放当前确认可用字段，后续可按需要逐步放开 sellerSkus、skuIds、updateTimeGe、updateTimeLe 等字段。
  • 第三方 Query/Header 中的鉴权、签名、店铺授权、游标分页等参数由内部接入层统一处理，本文档仅备份业务请求体参数。

3.2 商品详情查询

对外接口说明

该接口面向外部服务商提供单个 TikTok 商品详情查询能力。由于店铺名包含中文，对外使用 POST JSON Body 传参，避免 URL 参数转义问题；对外请求参数和响应字段统一使用 camelCase。

参数位置参数类型必填示例说明
BodyshopNamestring是美国TK-艾斯特尼-美区跨境1店店铺名称，用于内部匹配店铺授权、店铺密文和访问令牌。
BodyproductIdstring是1729592969712207008TikTok 商品 ID，对应内部第三方路径参数 product_id。

POST /openapi/tiktok-content/product/detail
Content-Type: application/json

四、通用接入要求

4.1 鉴权与安全

  • 所有接口必须通过 HTTPS 访问，不允许明文 HTTP。
  • 外部服务商通过 API Key / App Secret / 签名方式接入，具体方案由 IT API 网关统一实现。
  • 所有请求需记录调用方、接口路径、请求时间、响应状态、耗时和 traceId，便于审计与问题追踪。
  • 原则上只开放最小必要字段，不直接暴露 TikTok Shop、积加 ERP 或数据库内部敏感字段。

4.2 通用请求头

Header必填说明
Authorization是服务商访问凭证或签名结果，具体格式待网关方案确认。
X-App-Id是服务商应用 ID，用于识别调用方。
X-Timestamp是请求时间戳，用于防重放。
X-Trace-Id否调用链追踪 ID；未传时由网关生成。
