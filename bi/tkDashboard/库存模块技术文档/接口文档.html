库存模块 接口文档

基于库存模块两个原型页面整理：库存检查/htmls/TK库存检查-PID&SKU看板.html、缺补货/htmls/缺补货看板.html。文档格式参考销售数据接口文档，按页面交互、筛选项、汇总区、列表区、导出动作拆解接口。

通用约定

项说明
Base URL待定，建议 /api/bi/inventory
请求格式GET 使用 query string；POST 使用 application/json
响应格式application/json；导出接口返回文件流
分页page（从 1 开始）、pageSize（默认 20）；响应含 total
时间格式日期 YYYY-MM-DD；日期时间 YYYY-MM-DD HH:mm:ss
鉴权待定（Cookie / Token）

统一响应结构

{
  "code": 0,
  "message": "",
  "data": {}
}

code !== 0 表示业务错误，data 为接口约定结构。

零、公共筛选接口

当前仅保留搜索类型配置接口；站点、店铺等筛选值由前端固定选项或业务侧直接传值。

0.1 搜索类型选项

原型中库存检查支持 PID / SKU / SPU 搜索，缺补货支持 SPU / SKU 搜索。该接口也可以前端静态写死；若后续需要统一配置，可抽成公共接口。

GET /api/bi/inventory/options/search-types?module=inventoryCheck

响应 data

{
  "options": [
    { "label": "PID", "value": "pid" },
    { "label": "SKU", "value": "sku" },
    { "label": "SPU", "value": "spu" }
  ]
}

一、库存检查

对应页面：TK库存检查-PID&SKU看板.html。页面包含两个 Tab：PID&SKU维度、SPU维度。两个 Tab 共用筛选区，分别有列表、汇总卡片、导出按钮和“数据统计说明”弹框。

1.1 查询条件

  • 视图：sku（PID&SKU维度） / spu（SPU维度）
  • 站点：前端筛选条件，直接将选中的站点代码传给列表和汇总接口
  • 异常状态：全部 / 仅看异常 / 仅看正常 / 仅看待确认
  • 搜索：搜索类型 + 关键字
  • 同步日期：按日期查询当日库存快照

1.2 主表接口：库存检查列表

根据当前 Tab 返回对应粒度列表。建议一个接口通过 viewType 区分 SKU / SPU 两个视图。

POST /api/bi/inventory/check/page

请求体（JSON）

{
  "viewType": "sku",
  "siteCodes": ["US"],
  "statusFilter": "all",
  "keywordType": "sku",
  "keyword": "",
  "syncDate": "2026-04-12",
  "page": 1,
  "pageSize": 20
}

请求参数说明

参数类型必填说明
viewTypestring是sku / spu
siteCodeslist<string>否站点代码列表；支持多选或按区域展开
statusFilterstring否all / abnormal / normal / pending
keywordTypestring否SKU 视图支持 pid、sku、spu；SPU 视图建议固定为 spu
keywordstring否搜索关键字，支持模糊匹配
syncDatestring是同步日期，格式 YYYY-MM-DD
pagenumber否页码，默认 1
pageSizenumber否每页条数，默认 20

1.6 导出接口：导出明细 / 导出汇总 / 导出异常SPU

原型中 SKU 视图有“导出明细”，SPU 视图有“导出汇总”“导出异常SPU”。建议统一为一个导出接口，通过 exportType 区分。

POST /api/bi/inventory/check/export

请求体

{
  "viewType": "spu",
  "exportType": "abnormal",
  "siteCodes": ["US"],
  "statusFilter": "abnormal",
  "keywordType": "spu",
  "keyword": "",
  "syncDate": "2026-04-12"
}
参数说明
exportTypedetail（明细导出） / summary（SPU汇总导出） / abnormal（异常SPU导出）
