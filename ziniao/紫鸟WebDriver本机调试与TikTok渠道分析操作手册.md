# 紫鸟 WebDriver 本机调试与 TikTok 渠道分析操作手册

## 1. 目的与范围

本文记录本机通过紫鸟浏览器（Ziniao Browser）的 WebDriver 功能，打开已授权的 TikTok Shop 店铺并完成“渠道分析”数据导出的实际流程。

适用范围：macOS 本机调试、紫鸟浏览器已安装、目标 TikTok Shop 店铺已具备正常登录状态的情形。

本文不保存公司账号、用户名、密码、Cookie、Token、远程调试端口或店铺敏感信息。账号信息应仅保存在本机受权限保护的位置，且不得提交到 Git。

## 2. 最终效果

已完成并验证以下流程：

1. 启动紫鸟的本地 WebDriver 服务。
2. 通过本地接口读取浏览器/店铺列表，并以非无痕、非 Headless 模式启动指定店铺。
3. 使用已有会话进入 TikTok Shop Seller Center。
4. 进入“数据分析 → 渠道分析 → 视频与轮播照片 → 照片详情”。
5. 设定单日日期范围。
6. 分别切换“已绑定账号”和“联盟账号”，触发导出下载。

## 3. 前置准备

### 3.1 软件与权限

- macOS 设备。
- 已安装并可启动紫鸟浏览器。
- 已安装与紫鸟内核匹配的 ChromeDriver（紫鸟会在其 WebDriver 目录维护对应版本）。
- Python 3 与 Selenium，仅在需要通过 Selenium 验证远程调试端口时使用。
- 在“系统设置 → 隐私与安全性 → 辅助功能”中，为用于自动化的客户端授予辅助功能权限。缺少该权限时，浏览器可启动但无法可靠进行可视化点击。

### 3.2 账号与店铺状态

- 已在紫鸟中添加并授权 TikTok Shop 店铺。
- 店铺可在紫鸟中正常启动。
- 首次登录、短信/邮箱验证码、验证码、人机校验、风险验证等必须由人工完成；不要在脚本、文档或仓库中保存账号密码或验证码。
- 完成登录后，保留该浏览器配置的会话，以便后续自动化复用。

### 3.3 本地安全原则

- WebDriver API 只监听 `127.0.0.1`，不暴露到公网。
- 本地凭据文件使用最小权限，例如 `chmod 600`，且加入 `.gitignore`。
- 不在命令行回显、日志、截图文件名或文档中写入明文密码。
- 完成调试后，按需关闭 WebDriver 服务与店铺浏览器实例。

## 4. 启动紫鸟 WebDriver

### 4.1 使用 WebDriver 模式启动紫鸟

紫鸟客户端需以 WebDriver/HTTP 模式启动，并指定一个本地端口。例如本次运行使用本机回环地址的 `18888` 端口。

启动后，本地服务通常提供浏览器列表、启动浏览器等接口。先调用 `updateCore`，再调用 `getBrowserList`，确认核心及店铺列表可用。

> 端口、请求参数与接口名称应以紫鸟当前版本官方文档为准；不同客户端版本和核心版本可能不同。

### 4.2 获取并启动目标店铺

从 `getBrowserList` 结果中定位目标店铺，记录其浏览器标识后调用 `startBrowser`。

调试时推荐：

- `isHeadless: false`：显示浏览器，方便人工登录、校验与观察。
- `privacyMode: false`：保留该浏览器配置内的登录会话。

启动结果会返回本次实例的调试端口。该端口仅用于本机调试，不应写入固定配置或公开文档。

## 5. 调试端口验证与限制

### 5.1 Selenium 验证

如果需要确认浏览器已成功启动，可让与浏览器版本匹配的 ChromeDriver 连接到紫鸟返回的调试端口，并读取浏览器版本、窗口句柄或当前标签页。

该验证仅表示端口可达；不代表登录态、页面加载或页面元素操作一定成功。

### 5.2 Chromium DevTools 的限制

直接通过 Chrome DevTools Protocol WebSocket 连接时，可能遇到 Chromium 的 Origin 校验导致的 `403` 拒绝。此问题与业务站点登录无关。

处理原则：

- 不绕过浏览器安全校验，不伪造 DevTools Origin。
- 优先使用官方支持的 ChromeDriver/Selenium 方式，或对已显示的浏览器使用受系统权限控制的可视化自动化。
- 如版本不兼容，更新到与紫鸟核心匹配的 ChromeDriver，或采用人工操作完成关键步骤。

## 6. 必须人工触发或人工确认的环节

以下情况应保留人工处理：

| 场景 | 原因 | 建议做法 |
| --- | --- | --- |
| 首次登录 | 涉及账号密码和登录风险控制 | 用户在可见浏览器窗口内登录 |
| 验证码/人机校验 | 需要真实用户完成校验 | 用户自行处理后再继续 |
| 系统辅助功能授权 | 属于本机安全设置变更 | 用户在 macOS 设置中授权 |
| 浏览器空白页/登录页异常 | 可能与紫鸟核心、会话或站点加载有关 | 先刷新或重启目标店铺实例，必要时人工重新登录 |
| 需要对外提交、发布或修改业务数据 | 具有外部影响 | 操作前由用户确认 |

数据导出属于下载动作；在用户明确要求下载的前提下，可触发下载。导出完成时间由 TikTok Shop 后台决定。

## 7. TikTok Shop 渠道分析操作流程

### 7.1 进入页面

在已登录的 Seller Center 中：

1. 左侧导航打开“数据分析”。
2. 点击“渠道分析”。
3. 点击顶部“视频与轮播照片”。
4. 点击二级页签“照片详情”。

“渠道分析”顶部包括五个模块：

1. 直播
2. 视频与轮播照片
3. 商城页概览
4. 搜索
5. 订阅

### 7.2 设置 10 月 4 日单日范围

页面右上角打开日期选择器：

1. 选择“自定义”。
2. 选择开始日期为 `2026/10/04`。
3. 选择结束日期为 `2026/10/04`。
4. 等待页面重新加载；筛选区域应显示 `自定义：2026/10/04 - 2026/10/04`。

说明：页面时区显示为 `(GMT-08:00)`，报表口径以页面展示的时区与业务日期为准。若要导出其他年份或其他日期，按相同方式选择实际日期，不应沿用示例日期。

### 7.3 下载“已绑定账号”

1. 保持“照片详情”页。
2. 点击“已绑定账号”。
3. 确认表格数据刷新完成。
4. 点击表格工具栏中的下载图标（向下箭头）。
5. 页面出现“导出中，请稍等”即表示导出请求已触发。
6. 文件完成后会下载到浏览器的默认下载目录。

### 7.4 下载“联盟账号”

1. 点击“联盟账号”。
2. 等待表格加载完成，确认下载图标不再禁用。
3. 点击同一工具栏中的下载图标。
4. 页面出现“导出中，请稍等”即表示导出请求已触发。
5. 文件完成后会下载到浏览器默认下载目录。

> 切换账号标签后的短暂加载期间，下载图标可能禁用，或出现“您可以选择其他时间周期”等提示。此时等待数据表刷新后再点击下载。

## 9. 常见问题排查

### 浏览器显示空白页

1. 确认启动的是正确的店铺浏览器实例。
2. 先尝试刷新当前页面。
3. 若仍为空白，关闭该店铺实例并重新通过紫鸟启动。
4. 若登录态失效，由用户在可见窗口重新登录。
5. 检查网络、紫鸟核心版本和浏览器内核更新状态。

### 自动化看不到或无法点击页面

1. 确认 macOS 辅助功能权限已授予自动化客户端。
2. 使用可见模式启动浏览器，不使用 Headless 模式。
3. 页面发生导航或刷新后，重新读取页面元素，不能复用旧元素标识。

### 下载按钮无响应或被禁用

1. 确认日期筛选已完成、数据表已刷新。
2. 切换账号标签后等待加载结束。
3. 检查是否已有导出任务进行中。
4. 查看浏览器下载记录或默认下载目录，而不是仅依赖页面提示。

## 10. 建议的日常执行顺序

1. 打开紫鸟 WebDriver 服务。
2. 调用浏览器列表接口，定位目标店铺。
3. 非 Headless、非无痕启动店铺。
4. 人工完成首次登录与任何验证码。
5. 进入渠道分析的目标页面并设置日期。
6. 按账号类型逐个触发下载。
7. 在浏览器下载记录确认文件已生成。
8. 结束后关闭不再使用的浏览器实例和本地 WebDriver 服务。
