# 紫鸟照片详情自动导出实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用紫鸟本地 WebDriver API 启动已登录店铺，并由 Selenium 自动导出 TikTok Shop 照片详情中的已绑定账号和联盟账号数据。

**Architecture:** 脚本将店铺启动、浏览器附着、页面筛选、导出触发拆分为独立函数。默认日期为本机前一天，允许以命令行参数补数；日志只记录状态与错误，不记录凭据、Cookie 或调试端口。

**Tech Stack:** Python 3、requests、Selenium、标准库 unittest。

## Global Constraints

- 不保存账号、密码、Cookie、Token 或真实店铺标识。
- 紫鸟服务仅连接本机 `127.0.0.1`。
- 首次登录、验证码和人机校验由人工处理；脚本发现未登录即失败退出。
- 下载目录必须由调用者显式指定或使用本机默认下载目录。
