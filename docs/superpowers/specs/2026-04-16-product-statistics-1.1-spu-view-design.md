# 商品统计 1.1 SPU视图切换设计

## 背景

当前 `bi/tkDashboard/销售数据映射/htmls/商品统计-1.1.html` 基于原始 `商品统计.html` 拷贝而来，页面仍以原有商品统计视图为主，保留了 `PID` 相关字段和分析入口。

现业务要求在 `1.1` 版本中支持单独查看 `SPU` 统计信息，并在该视图中不展示 `PID`。

## 目标

在 `商品统计-1.1.html` 中新增按钮式视图切换：

- 支持 `PID统计` 与 `SPU统计` 两种视图
- 默认保留现有统计视图
- 切换到 `SPU统计` 后，不展示 `PID` 相关列和说明

## 设计方案

### 1. 改造范围

仅改动 `bi/tkDashboard/销售数据映射/htmls/商品统计-1.1.html`：

- 增加视图切换按钮
- 增加对应样式
- 增加轻量级前端切换逻辑
- 调整表头和导出说明文案

不改动原始 `商品统计.html`。

### 2. 交互方式

在页面上方新增按钮组：

- `PID统计`
- `SPU统计`

交互规则：

- 默认打开为 `PID统计`
- 点击 `SPU统计` 后切换到 `SPU` 视图
- 两个按钮互斥高亮

### 3. SPU视图规则

在 `SPU统计` 视图下：

- 不展示 `PID` 列
- 不展示与 `PID` 明细相关的分析按钮或入口
- 查询条件中的搜索字段仅保留 `SPU`
- 导出提示文案同步改为 `SPU` 视角

### 4. 实现方式

采用单页面双视图模式：

- 使用一个按钮组控制当前视图状态
- 通过前端脚本切换表头、列显示和说明文案
- 不新增独立 HTML 页面

## 验收标准

- 页面顶部存在 `PID统计 / SPU统计` 按钮组
- 点击 `SPU统计` 后页面可单独查看 `SPU` 统计
- `SPU统计` 视图中不展示 `PID`
- 原始 `PID统计` 视图仍可正常使用
- 原页面风格与查询、导出、切换逻辑保持一致
